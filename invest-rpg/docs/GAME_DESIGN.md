## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 모바일(iOS/Android) 2D 픽셀 투자 시뮬레이션 |
| 이야기 | 감으로 투자하다 전 재산을 잃은 20대 후반 청년이 공부하고, 인형 눈 붙이기로 모은 **1만 코인**으로 다시 시작한다 |
| 핵심 재미 | 시대별 실제 사건을 바탕으로 한 뉴스를 읽고, **공부한 만큼 미리 대비**해 수익을 낸다. 뉴스를 보고 따라 사는 것보다 단서를 읽고 미리 준비하는 쪽이 유리하다 |
| 화면 방식 | **하단 탭 4개의 1인칭 화면**: 거실 / 주식창 / 작업실 / TV홈쇼핑. 걷는 맵·캐릭터·이동 조작은 없다 (3차 기획에서 폐기) |
| 시대 | 2000년대 → 2010년대 → 2020년대 (1차 출시). 이후 시대는 데이터만 추가하면 늘어난다 |
| 시대 길이 | 시대당 게임 시간 2시간, 3시대 총 6시간. 2배속이면 실제 1시간씩 |
| 화폐 | **코인**. 주황색 코인 아이콘 (비트코인 ₿ 기호·로고는 쓰지 않는다) |
| 시작 자금 | 10,000 코인. 시대가 바뀌어도 자금은 계속 이월 |
| 돈을 늘리는 방법 | 투자, 인형 눈 붙이기(작업, **인형 100개를 완성하면 바로 지급**), 결제·광고 보상(나중, 즉시 입금) |
| 모드 | 실전 하나 (연습 모드·연습 지갑은 제거) |
| 이용 연령 | 14세 이상 |
| 언어 | 한국어·영어 (일본어·중국어를 나중에 추가할 수 있는 구조) |
| 상승·하락 색 | 한국어 기본 빨강 상승·파랑 하락, 영어 기본 초록 상승·빨강 하락. 설정에서 바꿀 수 있음 |
| 금지 | 실존 기업명·상표·인물명을 종목·뉴스에 쓰지 않는다. 투자 권유로 보이는 표현을 쓰지 않는다 ("게임 안 가상 수치, 투자 권유 아님" 안내) |

## 2. 전체 진행 흐름

```
앱 첫 실행
 └ (예정) 플레이 기록 동의 화면 · 튜토리얼 (엔진은 있음, 화면은 아직 없음)
 └ 2000년대 시작 ── 기본 탭: 주식창
     · 처음 7분 뉴스 없음 → 7분에 첫 뉴스(잠정) → 이후 4~7분 간격
     · 2시간 뒤 시대 종료 → 정산 창(투자 결과 = 다음 시대 시작 자금, 지급 대기 중인 작업 수입 안내) → 확인
     · 인형 100개(300터치)를 완성하는 순간 쌓인 작업 수입(300코인)이 현금에 한꺼번에 들어오고 지급 예정 +0·완성 0개로 돌아간다 (시대와 상관없이 이어짐)
 └ 2010년대 시작 (합계를 시작 자금으로 이월) ── 같은 흐름
 └ 2020년대 시작 ── 같은 흐름
 └ 최종 요약 창 (시대별 투자 수익률, 작업 수입 합계, 누적 수익률, 최종 코인) → '처음부터 다시'
```

- 앱을 껐다 켜면 **저장된 곳에서 그대로 이어진다** (14장). 앱이 업데이트되어 규칙이 바뀌었으면 저장 시점 가격으로 그 시대를 자동 정산하고 다음 시대부터 새 규칙.
- 끝난 판을 다시 열면 최종 요약이 보이고, '처음부터 다시'를 누르기 전까지 새 판을 저장하지 않는다.

## 3. 한 시대(2시간)의 흐름

| 게임 시간 | 일어나는 일 |
|---|---|
| 0:00 | 테마 풀 36개 중 20개 추첨 → 종목 20개, 모두 **1,000 코인**에서 시작. 화면은 주식창 탭, 안내 "처음 7분은 뉴스가 없어요. 종목을 둘러보며 준비해 보세요." |
| 0:00 ~ 0:07 | **뉴스 없음 (유예)**. 가격은 평소처럼 움직인다. 종목·기업 설명을 보며 준비 |
| 0:07:00 | **첫 뉴스 = opener 스토리의 잠정 뉴스** (초기 투자 방향을 잡기 좋은, 단서가 읽기 쉬운 사건) |
| 이후 | 4~7분 간격으로 뉴스. 시대당 평균 **약 21개** (속보 약 1/3, 잠정 약 1/3, 결과 약 1/3) |
| 뉴스 발표 순간 | 영향 종목 가격에 **75% 즉시 반영** → 5초 뒤 나머지 25% → 10초 동안 관성 출렁임 |
| 발표 120초 뒤 | 그 뉴스 아래 **주가 리포트 행**: 많이 움직인 종목 3개와 이유 |
| 잠정 뉴스 뒤 15분 안 | 그 스토리의 **결과 뉴스** (단서 쪽 65% / 반대 35%) |
| 종료 15분 전부터 | 새 잠정 뉴스를 시작하지 않는다 |
| 2:00:00 | **시대 종료**: 보유 종목 전량 자동 매도 → 투자 수익률 계산 → 정산 창 (작업 수입은 합산하지 않음, 인형 100개를 채우면 지급) |

- 틱(tick) = 가격이 한 번 바뀌는 단위 = 게임 시간 5초. 시대당 1,440틱.
- 뉴스가 떠도 **시간은 멈추지 않는다** (튜토리얼만 예외).

## 4. 화면 구성 — 공통 프레임

### 4.1 화면 크기와 그림 배율
| 항목 | 값 |
|---|---|
| 방향 | 세로 화면 |
| 지원 기준 | 최소 **360×640**과 **390×844**에서 모두 한 화면에 들어가야 한다 |
| 그림 기준 해상도 | **180×320** 픽셀, 정수 배율로만 확대 (360×640·390×844 모두 2배). 확대는 `image-rendering: pixelated` |
| 배경 그림 | 196×400 (가운데 180×320이 기본 영역, 좌우 8·위아래 40은 넓거나 긴 화면용 여백) |
| UI 안전 영역 | 그림 기준 위 20픽셀(상단 바), 아래 32픽셀(탭 바)에는 중요한 그림을 두지 않는다. 노치·홈 바는 기기별 자동 여백 |

### 4.2 전체 배치
```
┌─────────────────────────────┐
│ [NEWS!]     [⚙ 설정]   [🪙 10,000] │ ← 상단 바 (주식창에서는 계좌 바)
├─────────────────────────────┤
│                             │
│        탭 화면 (1인칭)        │
│                             │
├─────────────────────────────┤
│ [거실] [주식창] [작업실] [TV홈쇼핑] │ ← 하단 탭 바
└─────────────────────────────┘
```

### 4.3 하단 탭 바
| 순서 | 탭 | id | 1차 출시 | 아이콘(예정) |
|---|---|---|---|---|
| 1 | 거실 | `living_room` | 활성 | 소파 |
| 2 | 주식창 | `trading` | 활성 | 모니터 + 오르는 그래프 |
| 3 | 작업실 | `workshop` | 활성 | 인형 얼굴 |
| 4 | TV홈쇼핑 | `tv_shopping` | **비활성** (흐리게 표시, 눌러서 들어가면 "방송 준비 중" 화면, 이때 탭은 눌린 회색 버튼 모양) | TV |

- 탭 켜기/끄기는 코드 한 곳(`TAB_ENABLED`)만 바꾸면 된다.
- 지금 보고 있는 탭은 강조 표시.
- **시대 시작 때 기본 탭은 주식창** (새 종목 확인 유도). 그 외에는 마지막으로 보던 탭.

### 4.4 상단 바 (탭마다 다름)
| 탭 | 왼쪽 위 | 오른쪽 위 (설정 버튼의 왼쪽) | 맨 오른쪽 위 |
|---|---|---|---|
| 거실 | `NEWS!` (안 읽은 뉴스가 있을 때만 깜빡임) | 보유 현금 코인 (2배속이면 코인 왼쪽에 ▶▶) | 설정 버튼 |
| 주식창 | — (계좌 바가 상단을 차지, 4.5) | 계좌 바 안의 "남은 시간" | 설정 버튼 (계좌 바 위에 겹침) |
| 작업실 | `NEWS!` | 보유 현금 코인 + 그 아래 **지급 예정 작업 수입** ("지급 예정 +6 [코인 도트]", **코인 칩과 같은 크기**), 2배속이면 ▶▶ | 설정 버튼 |
| TV홈쇼핑 | `NEWS!` | 보유 현금 코인 (2배속이면 ▶▶) | 설정 버튼 |

- **보유 현금은 작업 중에 늘지 않는다** (작업 수입은 인형 100개를 채울 때 한꺼번에 들어온다). 작업실만 지급 예정 수입을 따로 보여준다.
- `NEWS!`는 **뉴스에만** 켜진다 (주가 리포트는 해당 없음). 누르면 주식창으로 이동. 주식창에 들어가면 모두 읽음 처리되어 사라지고, 주식창에 있는 동안 온 뉴스도 바로 읽음.
- **설정 버튼은 모든 탭에서 상단 맨 오른쪽 같은 자리** (오른쪽에서 12, 위에서 8 도트가 아닌 화면 픽셀 기준, 38×38). 모양은 톱니바퀴. 같은 자리에 있어야 찾기 쉽고, 엄지가 자주 닿는 아래쪽(탭 바·주문 버튼)과 멀어 잘못 누를 일이 적다.
- 상단 바 숫자는 틱마다 바뀌지만, 버튼은 다시 만들지 않는다 (누르는 도중 터치가 사라지지 않게).

### 4.5 주식창의 계좌 바 (상단 바 대신)
```
┌──────────────────────────────────┐
│ 총 자산            [⚙]   남은 시간 1:44:40 │
│ 🪙 10,000                  [1배][2배] │
│ 손익률 +0.0%                          │
└──────────────────────────────────┘
```
- 총 자산(현금 + 보유 종목 평가액), 손익률(**이번 시대 시간가중수익률**, 상승·하락 색), 남은 시대 시간.
- **배속 버튼 1배 / 2배 나란히** (하나를 켜면 다른 하나가 꺼짐). 탭을 옮겨도 배속은 유지.

### 4.6 안내 (토스트)
- 화면 아래(탭 바 위)에 짧게 2.2초. 최대 3개까지 쌓임. 오류는 다른 색.
- 예: 체결 안내 "노랑 제분주 9주 체결 (9,000 코인)", LP 장르 이름 "재즈", 시대 시작 안내.

## 5. 화면 구성 — 탭별 상세

### 5.1 거실 (1인칭)
| 요소 | 위치(기준 180×320) | 동작 |
|---|---|---|
| 배경 | 전체 | 시대별 거실 (2000년대 / 2010년대 / 2020년대) × **인테리어 단계 0~7** (13.4) |
| LP 플레이어 | x14~70, y150~194 (서랍장 위) | 누르면 장르가 **재즈 → 클래식 → 힙합 → 락 → 재즈** 순환 + LP 회전 애니메이션(2초) + 장르 이름 안내. "끄기" 없음 (음소거·볼륨은 설정) |
| 강아지 한 마리 | 기본 위치 러그 위, **바닥 전체와 소파 위를 돌아다님** (`DESIGN_HANDOFF.md` 8장) | **1번 터치: 서서 웃으며 꼬리 흔들기, 5번 연속 터치: 배 까고 눕기 + 하트** (13.2) |
| 인테리어 업그레이드 버튼 | 위쪽 (y≈104, 가운데) + 아래 단계 점 7개 | **"인테리어 업그레이드 - 2,000 [코인]"**. 누르면 2,000코인을 내고 한 단계 상승 (13.4). 마지막 단계는 "인테리어 완성"(비활성). *예전의 LP 안내 문구는 삭제 — LP를 누르면 음악이 바뀌는 기능은 그대로고, 휴대폰 브라우저는 첫 터치 전 소리가 안 나므로 **화면의 첫 터치가 소리 잠금 해제를 겸한다*** |

- 강아지는 가만히 있을 때(앉기·엎드리기) 숨쉬기(2프레임 반복), 움직일 때는 걷기 2프레임을 번갈아 쓴다.
- 시대별 강아지 단계: 2000년대 **강아지**(활발, 빠름) / 2010년대 **성견** / 2020년대 **노견**(느리고 부드러움).

### 5.2 주식창 (HTS 스타일)
**도트 스타일 패널**(2픽셀 외곽선, 모서리를 한 칸 깎은 모양, 단색 면). 색은 시대가 아니라 **밤/낮 두 세트**를 따른다 (`DESIGN_HANDOFF.md` 9장). 위에서 아래로 계좌 바(4.5) → 종목 목록 → 주문 패널 → 뉴스 피드이고, 첫 화면에서 **종목표부터 최신 뉴스 한 건까지 스크롤 없이** 보인다.

```
┌ 종목 ─────────────────────────────┐
│ ★  종목명            현재가    등락률 │
│ ★  노랑 제분주          808   -19.2% │ ← 7줄 보이고 나머지는 스크롤
│ ☆  노을 엔터주        1,008    +0.8% │
│ …                                    │
├ 노랑 제분주   808 -19.2%  [차트][×] ─┤ ← 주문 패널 (종목을 누르면 열림)
│ ~~~~ 최근 20분 미니 차트 (접기) ~~~~ │
│ 수입한 밀과 원당으로 밀가루와 설탕을 만든다. │
│ 보유 없음 / 보유 3주 · 평균 1,020 · 평가 -2.1% │
│ [매수][매도] [−][  12 ][+][최대]       │
│ 필요 9,715 코인 (수수료 19)   [ 매수 ] │
├ 뉴스 ─────────────────────────────┤
│ [결과] 고병원성 조류인플루엔자 확진…  0:13:15 │ ← 최신 뉴스: 제목 + 본문 펼침
│  본문 2~3줄                            │
│  ┌ 주가 리포트 ──────────────────┐   │ ← 발표 120초 뒤 붙는 행
│  │ 들꽃 양계주 -17.4% — 대규모 살처분… │   │
│  │ 발표 즉시 -13.0% · 5초 뒤 -4.4% · 합계 -17.4% │
│  │ 외 1종목                       │   │
│  └───────────────────────────┘   │
│ [잠정] 닭 집단 폐사 신고…        0:07:00 │ ← 이전 뉴스: 제목 한 줄 (누르면 펼침)
└──────────────────────────────────┘
```

**종목 목록**
- 열: 즐겨찾기 별(도트 별 모양, 켜짐은 노랑·꺼짐은 흐린 색) · 종목명 · **최근 20분 미니 추이선** · 현재가 · 등락률.
- 등락률 = **시대 시작가(1,000) 대비 누적 변화율**. 색은 설정의 상승 색상 모드.
- 정렬: **즐겨찾기 먼저, 그 안팎은 가나다순** (테마 분위기·관련도와 무관). 산 종목은 자동 즐겨찾기.
- 5초마다 가격이 바뀌면 그 칸이 잠깐 번쩍인다 (오르면 상승색, 내리면 하락색).
- 한 번에 7줄 보이고 나머지는 스크롤. 종목을 누르면 주문 패널이 열리고, 같은 종목을 다시 누르거나 ×로 닫는다.

**주문 패널**
- 종목명·현재가·등락률, **최근 20분 미니 차트**(접을 수 있음), 기업 설명 1~2줄, 보유 수량·평균 매수가·평가 손익률.
- **수량 입력칸 + −/+ 버튼 + '최대'** 로 수량을 맞춘 뒤 **[매수](빨강) / [매도](파랑) 버튼을 바로 눌러** 주문한다 (매수·매도를 먼저 고르는 단계 없음). '최대': 매수 쪽은 수수료 포함해 살 수 있는 최대 수량 (`floor(현금 ÷ (현재가×1.002))`), 매도 쪽은 보유 수량 전부.
- 주문 전에 "필요 ○○ 코인 (수수료 ○○)" / "받을 ○○ 코인"을 미리 보여주고, 현금·보유 수량이 부족하면 오류 문구를 미리 보여준다.
- 주문은 **현재가로만, 확인 창 없이 한 번에 체결**하고 짧은 안내(체결 수량·금액). 오류 문구 예: "현금이 부족합니다.", "보유 수량이 부족합니다."
- 주문하지 않고 패널을 닫으면 "망설임"으로 기록된다 (16장).

**뉴스 피드**
- 뉴스는 **팝업이 아니다**. 시간을 멈추는 창은 없다.
- 최신순. 뉴스 창은 **뉴스 한 건이 딱 들어가는 높이**이고, 이전 뉴스는 **아래로 스크롤**해서 본다. 한 건 = 종류 표시 + 시각 / **제목 한 줄**(길면 줄이거나 요약해서 항상 한 줄) / **본문 3줄 이내** / 주가 리포트(발표 120초 뒤).
- 뉴스 종류 표시: 속보 / 잠정 / 결과 (단서 뉴스도 "잠정"으로 표시). 결과 뉴스 중 실제와 다른 쪽은 "가상 시나리오" 태그.
- **발표 120초 뒤 그 뉴스 바로 아래에 '주가 리포트' 행**: 종목별 1~2줄 `{종목} {합계 %} — {이유}`, 세부 "발표 즉시 ○% · 5초 뒤 ○% · 합계 ○%", 최대 3종목 + "외 N종목". 잠정 뉴스 리포트에는 "잠정 발표라 영향이 작았고, 결과 발표에 따라 크게 달라질 수 있어요." 결과 뉴스가 예상과 반대로 반응했으면 이유 한 줄.
- 처음 본 리포트 아래 한 번만 "주가 리포트의 반영률은 게임 안에서 실제로 반영된 값이에요. 실제 시장 수치나 투자 권유가 아닙니다."
- 새 뉴스·새 리포트는 잠깐 강조. **호재/악재 방향 표시는 하지 않는다.**
- 뉴스가 하나도 없을 때(처음 7분): "처음 7분은 뉴스가 없어요. 종목을 둘러보며 준비해 보세요."

### 5.3 작업실 (1인칭)
| 요소 | 위치(기준 180×320) | 동작 |
|---|---|---|
| 배경 | 전체 | 시대별 작업실 (작업대, 실·도구, 선반 등) |
| 인형 | x70~110, y140~188 (작업대 위; 인테리어 단계 낮을 때는 박스·접이식 상 위) | 터치 한 번마다 **눈 하나 → 눈 둘 → 완성**. 완성하면 옆으로 빠져나가고 눈 없는 인형이 새로 들어옴 |
| "+3" 효과 | 인형 → 상단 "지급 예정" 숫자 | 완성할 때 날아가서 숫자가 늘어남 |
| 진행 표시 | 인형 아래 | "눈 1개 · 완성 2개" |

- 진행 중인 인형(눈 0~2개)은 탭을 옮겨도, 저장해도, 다음 시대로 넘어가도 유지.
- 작업 화면이 열려 있어도 게임 시간은 흐른다.

### 5.4 TV홈쇼핑 (1차 비활성)
- TV가 받침대 위에 놓이고, 화면에 **"방송 준비 중"** 글자와 지지직 노이즈(4프레임 반복). 방 모습은 **인테리어 단계(0~7)를 거실·작업실과 똑같이 따른다** (상자 위 TV → … → TV장·액자·화분, `DESIGN_HANDOFF.md` 16.5). 시대별 TV 모양(2000년대 브라운관 / 2010년대 평면 / 2020년대 대형 평면)은 **지금 그림이 브라운관 하나뿐**이다.
- 터치해도 아무 일도 일어나지 않는다. 나중에 활성화할 때 코드 한 곳만 바꾸면 된다. (광고 보상 등은 나중에 이 탭에서 다시 검토)

## 6. 화면 구성 — 창과 개발용 화면

### 6.1 시대 종료 정산 창
```
┌ 2000년대 정산 ──────────────┐
│ 투자 결과      10,000 코인 (+0.0%) │
│ = 다음 시대 시작 자금  10,000 코인 │
│ 지급 예정 6코인: 인형 98개 더 완성하면 지급 │
│ 보유 종목은 모두 현재가로 자동 매도되었습니다. │
│ ▶ 2000년대 돌아보기 (접힘)        │
│            [ 확인 ]              │
└────────────────────────────┘
```
- **투자 결과(코인·수익률)**가 다음 시대 시작 자금이 된다. 아직 지급되지 않은 작업 수입은 정산 창에 한 줄로 안내만 하고 합산하지 않는다 (인형 100개를 채우면 현금으로 들어온다).
- 접힌 "돌아보기"(시대가 끝난 뒤에만 공개): 이번 판 테마별 분위기(긍정/부정/중립)·비중(주요/배경), 스토리마다 잠정 뉴스 → 단서가 가리킨 결과 → 실제 결과("단서대로 나왔어요 / 반대로 나왔어요"), 뉴스별 영향 종목과 영향도·연결 강도(직접/밀접/간접), 주가 리포트 전체.
- 앱 업데이트로 자동 정산된 경우 안내: "게임이 업데이트되어 저장 시점의 가격으로 이 시대를 정산했어요. 다음 시대부터 새 버전이 적용돼요."
- '확인' → 다음 시대 시작 (주식창 탭, 7분 유예 안내). 마지막 시대면 최종 요약.

### 6.2 최종 요약 창 (마지막 시대 뒤)
- 시대별 줄: "{시대}: 투자 수익률 {%}, 작업 수입(지급 완료) {코인}"
- 지급 완료된 작업 수입 합계(아직 지급 전인 금액은 "지급 예정"으로 따로 표시, 최종 코인에는 넣지 않음), 누적 투자 수익률(시대별 수익률의 곱), **최종 코인**.
- '처음부터 다시' → 세이브를 지우고 새 게임.

### 6.3 설정 창
| 항목 | 내용 |
|---|---|
| 언어 | 한국어 / English |
| 상승 색상 | 언어에 맞춤(기본) / 빨강 상승·파랑 하락 / 초록 상승·빨강 하락 |
| 전체 볼륨 · 음악 볼륨 · 효과음 볼륨 | 0~100 (기본 100 / 40 / 80) |
| 음소거 | 켜기/끄기 |
| 플레이 기록 보내기 (동의) | 기본 꺼짐 |
| 음악 저작권 표시 | 출처 표기가 필요한 곡 목록 (접힘) |

- 설정은 게임 세이브와 별개로 기기에 저장된다. 언어를 바꾸면 화면 글자가 바로 바뀐다.

### 6.4 아직 만들지 않은 화면 (기획에 있음)
- 튜토리얼 화면 (엔진은 완성: 5분짜리 판, 뉴스 1개에서 시간 정지 → 매수 → 반영 → 리포트)
- 첫 실행 플레이 기록 동의 화면 (문구는 준비됨: 제목 "플레이 기록 수집 동의", 본문, 동의/동의하지 않음)
- 시작 시 언어·연령 확인 화면, 결제·광고, 랭킹

### 6.5 개발용 디버그 패널 (`?debug=1`, 출시 빌드에서 자동 제거)
- 처음엔 작은 'DEBUG' 버튼만, 누르면 펼침.
- 시드 고정·시대 선택 후 새 게임, 시간 10배, 다음 뉴스까지 건너뛰기, +5분, 시대 끝까지, +1000 코인.

## 7. 정보 숨김 규칙 (화면이 지켜야 할 것)

- 화면은 **공개용 데이터(`PublicGame`)만** 받는다. 엔진 내부의 뉴스 영향 방향·규모, 테마 분위기·비중, 스토리 결과 확률은 플레이 중 화면으로 가지 않는다.
- 플레이 중 표시 금지: **모든 뉴스의 호재/악재 방향**, "관련 테마", 화살표·색으로 방향 암시, "수혜" 같은 말, **테마 분위기(긍정/부정/중립)와 비중(주요/배경)**.
- 종목·뉴스 id는 판마다 바뀌는 무작위 문자열 (앱 데이터를 들여다봐도 정답을 알 수 없게).
- 종목 목록 순서는 즐겨찾기 + 가나다순 (데이터에 저장된 순서가 드러나지 않게).
- 주가 리포트는 반영이 끝난 사실이라 방향과 %를 보여준다.
- **시대가 끝난 뒤에만** 돌아보기로 전부 공개 (사후 학습).

## 8. 시장 규칙

### 8.1 가격
| 항목 | 값 |
|---|---|
| 시작 가격 | 시대마다 모든 종목 1,000 코인 |
| 평소 변동 | 틱(5초)마다 -1.5% ~ +1.5% (0.1% 단위) |
| 1분 한도 | 12틱 누적 ±3%. 넘치면 넘친 만큼 반대로 튕긴다 |
| 뉴스 사이 한도 | 뉴스 발표 순간 가격(P0) 기준, 다음 뉴스 전까지 0.7×P0 ~ 1.3×P0 (첫 뉴스 전에는 1,000 기준) |
| 가격 | 정수, 최소 1 코인 |
| 차트 | 최근 20분(240틱) 보관 |

### 8.2 뉴스 반영
| 항목 | 값 |
|---|---|
| 반영률 | 영향도 × 3% × 배율, 결과는 ±30%로 자른다 |
| 배율 | 연결 강도 3(직접): 0.6~1.4 / 강도 2·1(간접): 0.4~1.6 (영향마다 무작위) |
| 반영 시점 | **발표 순간 75%** + **5초 뒤 25%** |
| 관성 | 반영 뒤 2틱(10초): 같은 방향 50% / 반대 25% / 없음 25%, 크기 0.1~1.5% |

- 발표 순간 75% 반영의 이유: 이전 규칙(전부 5초 뒤)은 뉴스를 보고 5초 안에 사면 시대당 +536%까지 버는 허점이 있었다.

## 9. 뉴스 시스템

### 9.1 뉴스 종류
| 종류 | 설명 | 규모(1~10) |
|---|---|---|
| 속보 | 예고 없이 나오는 단독 뉴스 | 3~9 |
| 잠정 | 아직 확정되지 않은 소식, 스토리의 시작. 본문에 결과 쪽 **단서**가 있다 | 1~3 |
| 결과 | 잠정 뉴스의 결말. 스토리마다 서로 반대인 2개를 준비, 하나만 나온다 | 7~9 |
| 단서(후속) | 잠정과 결과 사이에 나오는 후속 뉴스 (선택, 화면에는 "잠정"으로 표시) | — |

### 9.2 일정
- 처음 7분 유예, 첫 뉴스는 정확히 7분의 **opener 스토리 잠정 뉴스** (모든 시대 적용, 튜토리얼 제외).
- 이후 4~7분(240~420초) 간격. 빈 자리마다, 진행 중인 스토리가 없으면 85% 확률로 새 잠정 뉴스, 아니면 속보.
- 동시에 진행되는 스토리는 1개. 결과는 잠정 뉴스 뒤 15분 안. 시대 종료 15분 전부터 새 잠정 뉴스 없음.
- 결과 추첨: **단서 쪽 65%** / 반대 35%. 한 판에 같은 스토리는 한 번뿐이라 확신보다 분산 투자를 유도.
- 같은 뉴스는 한 시대에 다시 나오지 않는다. 마지막 뉴스는 반영·관성이 시대 안에서 끝나는 시점까지만.
- 결과 뉴스는 이어진 잠정 뉴스와 연결해 보여줄 수 있다 ("관련 잠정 뉴스").

### 9.3 주가 리포트 (발표 120초 뒤)
- 실제로 반영된 종목 중 반영률 크기 상위 3개 + 나머지 개수.
- 각 줄: 종목, 합계 %, 이유(데이터에 쓴 한 줄 이유, 없으면 자동 문구), 즉시분·5초 뒤분.
- 시간이 부족해 시대 안에 120초가 안 남으면 만들지 않는다 (돌아보기에는 전부 들어간다).

## 11. 계좌·매매·수익률·경제

| 항목 | 값 |
|---|---|
| 시작 자금 | 10,000 코인 |
| 매매 | 현재가로만, 정수 주 단위, 확인 창 없음 |
| 수수료 | 매수·매도 각 0.2% (내림, 매입원가에 포함) |
| 평균가 | 이동평균 |
| 관심 종목 | 사면 자동 추가, 목록 맨 위 |
| 수익률 | **시대별 시간가중수익률**: 입금 때마다 구간을 나눠 구간 수익률을 곱한다 (입금이 수익으로 잡히지 않음). 정산·랭킹 모두 이 값. 누적 = 시대별 수익률의 곱 |
| 자금 이월 | 다음 시대 시작 자금 = 투자 결과 + 그 사이 지급된 작업 수입(인형 100개 묶음 지급분·입금) |

### 11.1 수입 종류
| 수입 | 지급 시점 | 수익률 |
|---|---|---|
| 투자 | 매매 즉시 | 시간가중수익률 대상 |
| 작업 (인형 눈) | **인형 100개를 채우는 순간 한꺼번에** | 입금과 같이 처리: 지급 순간 수익률 구간을 나누고 수익으로 세지 않음 |
| 결제 | 즉시 입금 (SDK는 나중) | 수익으로 세지 않음 |
| **인테리어 업그레이드 (지출)** | 누른 즉시 보유 현금에서 2,000코인 차감 (7번, 총 14,000) | 출금처럼 처리: 구매 순간 구간을 나누고 손실로 세지 않음 |
| 광고 보상 | 즉시 입금 (나중) | 수익으로 세지 않음 |

### 11.2 시대 종료 처리 순서
1. 보유 종목을 현재가로 전량 청산
2. 투자 수익률 계산 (작업 수입 제외)
3. (작업 수입은 합산하지 않는다. 지급 대기분은 그대로 유지)
4. 투자 결과를 다음 시대로 이월

### 11.3 파산 대기 시간
- 현금이 가장 싼 종목 1주 값보다 적고 보유 종목도 없는 시간. 정산 결과와 기록에 남긴다. 길면 "작업 수입 일부 선지급" 같은 장치를 검토 (지금은 없음).

### 13.2 강아지
- **터치 반응** (이전의 "매 터치 쓰다듬기, 3번째마다 무작위 반응"을 대체): **1번 터치 = 그 자리에 서서 웃으며 꼬리 흔들기**(2.5초), **5번 연속 터치 = 배를 까고 드러누워 꼬리를 흔들고 몸통 주위로 하트가 올라옴**(4초). 연속 = 직전 터치와 1.5초 이내. 5번째에서 배 까기로 바뀌고 횟수 초기화, 배 까기 중에는 터치를 세지 않는다. 소파 위에서 누르면 바닥으로 내려온 뒤 반응. 스프라이트·타이밍은 `DESIGN_HANDOFF.md` 17장.
- 시대별 단계와 속도: 강아지(2000년대) 1.3배 / 성견(2010년대) 1.0배 / 노견(2020년대) 0.6배.
- 연출용 난수는 시장 난수와 완전히 분리 (강아지를 몇 번 만져도 가격·뉴스는 그대로).
- **돌아다니기**: 강아지는 한 자리에 있지 않고 스스로 움직인다. 걷기 → 멈춤 → 바닥에 앉기·러그에 엎드리기·소파로 점프해 앉기 → 쉼(3~9초) → 다시 걷기. 걷는 속도·쉬는 시간은 시대별 속도 배수(위)를 따른다. 상태표와 좌표는 `DESIGN_HANDOFF.md` 8장.
- **LP판을 누르면 음악 장르가 바뀐다** (거실의 안내 문구는 없앴다. 대신 그 자리에 인테리어 업그레이드 버튼).

## 14. 시간·배속·일시정지·저장

| 항목 | 규칙 |
|---|---|
| 틱 간격 | 1배 5,000ms, 2배 2,500ms (게임 시간 단위는 같음) |

| 일시정지 사유 | `tutorial`(튜토리얼 뉴스) · `background`(앱이 화면에서 사라짐)만. 주가 리포트는 멈추지 않음 |
| 백그라운드 | 멈추고, 돌아와도 밀린 시간을 몰아서 따라잡지 않는다. 숨긴 상태로 열리면 처음부터 일시정지 |

| 저장 내용 | 시드, 시대 순번, 시작 자금, 추첨 결과, 지난 시대 요약, 이번 시대 행동(매매·입금·작업), 읽음 상태, 버전(엔진·콘텐츠·밸런스), 상태 스냅샷 |

## 17. 콘텐츠 작성 기준

### 17.1 테마·종목
- 테마마다 핵심 단어 5~8개, "그 시대에 존재했다"는 근거 한 줄 (모르면 "확인 필요"). 그 시대에 없던 테마는 넣지 않는다.
- 종목명: 한국어 **"수식어 + 업종/테마명" 붙여쓰기, '주'를 붙이지 않음** (예: 강물신문, 구슬제약, 노랑제분, 노을엔터, 단풍중장비), 영어 **"… Stock"**. 실존 기업명·상표·인물명 금지.
- 금지 단어(평가·전망 어감): 최강, 최고, 폭등, 폭락, 급등, 급락, 유망, 위기, 호황, 불황, 대박, 성장, 번영, 승리, 황금, 행운 등. "평화"처럼 뉴스 방향을 암시할 수 있는 수식어는 경고.
- 기업 설명: **1~2줄(80자 안팎)**, 제품·서비스 중심 중립 서술. 전망·평가 표현(유망, 전망, 기대, 선도, 1위, 수혜, 저평가 등) 금지.

### 17.2 뉴스
- 뉴스마다 영향 테마 6~9개, 호재·악재를 섞는다.
- 영향도 공식: `|영향도| = max(1, 반올림(규모 × 계수))`, 계수 = 직접(강도 3) 1.0 / 밀접(2) 0.6 / 간접(1) 0.3. ±1 조정은 이유를 적는다.
- 강도 3: 뉴스 본문 단어가 테마 핵심 단어와 일치. 강도 2·1: 연결 설명(chain) 한 줄.
- 영향 큰 상위 4개는 주가 리포트용 한 줄 이유 필수 (한국어).
- 분위기 편향 75%: 긍정 테마는 약 75% 호재, 부정은 약 75% 악재, 중립은 반반.
- 배경 테마도 뉴스 풀 전체에서 2번 이상 영향을 받는다.
- 본문은 신문 기사처럼 2~3줄, **연도·월 표기 금지** (뉴스는 시대 안에서 무작위 순서).
- 제목·본문에 방향을 직접 알려주는 표현 금지: 호재, 악재, 수혜, 수혜주, 타격주, 상승 예상, 하락 예상 ("유가 급등"처럼 사건 자체는 괜찮다).

### 17.3 스토리
- 잠정 뉴스 1개 + 서로 반대인 결과 2개 + 단서(선택). 잠정 본문은 결과를 확정하지 않고 한쪽으로 기우는 단서가 읽히게.
- **단서가 가리키는 결과 = 실제 역사** (역사를 공부한 사람과 단서를 읽은 사람이 같은 쪽에 서게).
- **opener**(시대 첫 뉴스 후보: 단서가 읽기 쉽고 사건이 직관적인 것) 시대당 3개 이상.
- 결과가 예상과 반대로 반응한 실제 기록이 있으면 그 이유를 쓴다 (리포트에 나옴).

### 17.4 양과 점검
- 시대당 테마 36개·종목 36개, **속보 20개 이상, 스토리 12개 이상** (다른 시대 작업 전까지).
- `npm run lint:content`로 자동 점검, 실제 사건 근거는 시대별 팩트체크 표(`docs/2000s_fact_check.md`). 팩트체크 문서에만 실명을 쓰고 게임 데이터에는 쓰지 않는다.

## 23. 기술 구조

- **언어·도구**: TypeScript, Vite(화면 개발 서버·빌드), Vitest(테스트), Playwright(스크린샷·브라우저 점검). 화면은 라이브러리 없는 바닐라 TypeScript (Phaser는 쓰지 않음). 앱 포장은 나중에 Capacitor.
- **엔진과 화면 분리**: 게임 규칙 엔진(`src/engine/`)은 시계·화면·인터넷을 쓰지 않는다 (테스트로 강제). 화면 타이머가 틱마다 엔진을 부른다.
- **같은 시드 = 같은 결과**: 뉴스·가격이 항상 똑같이 나온다. 세이브(행동 리플레이)와 데이터 분석이 이 성질을 쓴다.
- **화면 ↔ 엔진 창구**: `PublicGame` (공개용 뷰) 하나. 탭 규칙은 `TabController`.
- **디자인 교체 방법**: 그림은 `src/ui/artManifest.json`의 파일명대로 `assets/art/`에 덮어쓰기, UI 스타일은 `src/ui/style.css` 교체. 화면 동작 코드는 그대로.
- **확인 명령**: `npm run dev`(화면), `npm run check`(타입·테스트 287개), `npm run e2e`(브라우저 흐름 20개), `npm run shots`(스크린샷), `npm run sim`·`sim:repeat`·`sim:carry`(밸런스), `npm run lint:content`, `npm run lint:audio`.
