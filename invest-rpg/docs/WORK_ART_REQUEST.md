# 시대별 작업(근로소득) 그림 요청서 (12차)

> 기획 결정 (2026-10-13, 사용자): 시대가 바뀌면 작업실의 일이 그 시대에 어울리는 일로 바뀐다.
> 터치 방식은 그대로다: **3번 누르면 작업물 1개 완성**, 100개마다 지급, 보상은 인생 업그레이드 단계마다 터치 1번당 +1코인.
> 코드로 그린 임시 그림은 쓰지 않으므로, **이 그림이 오기 전까지 게임에는 2000년대 인형 눈 붙이기만 나온다.**

## 1. 시대별 작업

| 시대 | 작업 | 시대 배경 | 1번째 터치 | 2번째 터치 | 3번째 터치 (완성) |
|---|---|---|---|---|---|
| 2000년대 | **인형 눈 붙이기** (지금 그대로) | 가내 부업의 상징 | 눈 하나 | 눈 둘 | 완성 |
| 2010년대 | **스마트폰 케이스 큐빅 붙이기** | 스마트폰 대중화, 폰 꾸미기 유행 | 큐빅 한 줄 | 큐빅 두 줄 | 완성 (반짝이는 케이스) |
| 2020년대 | **택배 상자 포장** | 온라인 쇼핑·새벽 배송 | 물건 넣기 | 테이프 붙이기 | 송장 붙이기 (완성) |

- 화면 안내 문구는 시대마다 바꾼다 (예: "케이스 100개를 완성하면 보상이 지급돼요", "상자 100개를 포장하면 …").
- 실존 브랜드 로고·상표는 그리지 않는다 (케이스·상자·송장에 회사 이름 없음).

## 2. 지금 그림의 문제

지금 작업실 그림(`workshop_{era}_{night|day}_lv{0..7}.png`, 130×281 도트, 세로 3칸 = 843)은
**배경과 작업 중인 인형이 한 장에 같이 그려져 있다** (칸 0·1·2 = 눈 0·1·2개).
2010·2020년대 그림도 2000년대 구성에 팔레트만 바꾼 것이라 인형이 들어 있다.
작업을 바꾸려면 이 그림을 다시 그려야 하는데, 지금 방식 그대로면 **2시대 × 밤/낮 × 8단계 = 32장(96칸)**이다.

## 3. 요청: 배경과 작업물을 나눠 주세요 (권장)

그릴 양을 줄이고, 나중에 작업을 또 바꾸기 쉽게 **배경과 작업물을 따로** 받고 싶다.

### 3.1 작업물 그림 (새로)
| 파일 | 크기 | 내용 |
|---|---|---|
| `work/doll_eyes_0.png` · `_1.png` · `_2.png` | 26×37 | 2000년대 인형 (지금 그림에서 인형만 오려 내도 됨) |
| `work/phone_case_0.png` · `_1.png` · `_2.png` | 26×37 이내 | 2010년대 폰 케이스: 큐빅 0줄 / 1줄 / 2줄 |
| `work/parcel_box_0.png` · `_1.png` · `_2.png` | 26×37 이내 | 2020년대 택배 상자: 빈 상자 / 물건 들어 있음 / 테이프 붙임 |

- 투명 배경 PNG, 도트 1칸 = 1픽셀 (게임이 3배로 키운다).
- 작업물을 놓는 자리는 지금 인형 자리와 같다: **Lv0 (52,155) 박스 위 / Lv1~2 (48,135) 접이식 상 / Lv3~7 (52,133) 책상** (그림 왼쪽 위 모서리 기준).
- 밤/낮을 따로 그리지 않아도 된다 (배경과 같은 빛이 필요하면 `_night` 버전을 추가).

### 3.2 작업실 배경 (다시)
| 파일 | 내용 |
|---|---|
| `workshop_{era}_{night\|day}_lv{0..7}.png` | **작업물 자리를 비운 배경 1칸** (130×281, 세로 3칸 시트가 아니라 1칸) |

- 2000년대는 지금 그림에서 가운데 인형만 지우면 된다.
- 2010·2020년대는 시대 소품을 바꿔 주면 좋다 (아래 3.3).

### 3.3 시대 소품 (선택, 배경에 함께)
| 단계 소품 (DESIGN_HANDOFF 16.3) | 2000년대 | 2010년대 | 2020년대 |
|---|---|---|---|
| 재료 봉지 (Lv0, (30,183)) | 눈알 봉지 + 접착제 | 큐빅 통 + 핀셋 | 테이프 커터 + 송장 묶음 |
| 바닥 상자 속 미완성품 (Lv1) | 눈 없는 인형 2개 | 민무늬 케이스 2개 | 접힌 상자 2개 |
| 선반 위 완성품 (Lv2~5) | 완성 인형 2~5개 | 완성 케이스 2~5개 | 포장된 상자 2~5개 |
| 큰 도구 (Lv6) | 재봉틀 | 케이스 지그(고정 틀) | 송장 프린터 |

## 4. 그림이 오면 하는 일 (코드 쪽)

1. 장면 층을 "배경 1칸 + 작업물 그림 3장"으로 바꾼다 (지금은 세로 3칸 시트).
2. 시대별 작업 종류(`WORK_TYPE`)와 안내 문구를 시대마다 바꾼다.
3. 시대가 바뀌어도 다 못 채운 묶음은 "작업 개수"로 이어진다 (예: 인형 40개 → 케이스 40개째부터).
4. 튜토리얼의 "인형 눈 붙이기" 설명에 "시대마다 일이 바뀐다"를 덧붙인다.
