# 시대별 작업창 그림 전달 (요청서: WORK_ART_REQUEST.md)

## 구성
- `work/` 작업물 스프라이트 — 투명 PNG, **26×41**, 도트 1칸 = 1px (게임이 ×3)
  - `doll_eyes_{0,1,2}.png` (2000년대, 눈 0/1/2개) · `phone_case_{0,1,2}.png` (2010년대, 큐빅 0/1/2줄) · `blog_post_{0,1,2}.png` (2020년대, 빈 화면/제목만/제목+본문)
  - `*_done.png` (선택): 3번째 터치 완성 순간(반짝임). 케이스=큐빅 3줄, 블로그=사진+제목+본문+발행 버튼. 쓰지 않아도 됨.
  - `*_night.png`: 밤 배경용(윤곽선 `#0c0818` + 따뜻한 조명 색 입힘). 낮은 접미사 없는 파일.
- `scene/workshop_{2000s|2010s|2020s}_{night|day}_lv{0..7}.png` 48장 — **130×281 한 칸, 작업물 자리 비움** (3칸 시트 아님). 인형 그림 포함하지 않음.
- `preview/` 확인용 JPG (스프라이트 상태표, 시대·밤낮별 Lv0~7 가로 시트: 눈 1개/케이스 1줄/제목만 상태를 올려 둔 모습)

## 배치
- 스프라이트 왼쪽 위를 **(slot_x, slot_y − 3)** 에 놓는다 (캔버스가 요청서의 26×37보다 4줄 큰 이유: 인형 모자 방울·윤곽선이 위로 3칸 나옴, 모든 작업물 하단 = 슬롯 기준 +37행).
  | 단계 | slot |
  |---|---|
  | Lv0 | (52,155) 박스 위 |
  | Lv1~2 | (48,135) 접이식 상 |
  | Lv3~7 | (52,133) 책상 |
- 작업물 그림자는 배경에 포함. 배경 → 작업물 순서로 그린다.
