# 투자 RPG (가제) — 기획 정리

> 지금까지 확정된 규칙, 밸런스 결과, 콘텐츠 작성 기준, 데이터 수집 계획, 결정이 필요한 항목과 앞으로의 일정을 한 문서에 모았다.
> 세부 근거는 `README.md`, `docs/logic_review.md`, `docs/telemetry.md`에 있다.

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 모바일(iOS/Android) 2D 픽셀 RPG풍 투자 시뮬레이션 |
| 이야기 | 감으로 투자하다 전 재산을 잃은 20대 후반 청년이 공부하고, 인형 눈 붙이기로 모은 1만 코인로 다시 시작한다 |
| 핵심 재미 | 시대별 뉴스를 읽고, 공부한 만큼 미리 대비해 수익을 낸다 |
| 이용 연령 | 14세 이상 |
| 언어 | 한국어·영어 (나중에 일본어·중국어 추가 가능한 구조) |
| 시대 | 2000년대 → 2010년대 → 2020년대 (시대는 데이터만 추가하면 늘릴 수 있음) |
| 모드 | 실전 하나 (연습 모드·연습 지갑은 제거. 광고는 나중에 TV 기능으로 다시 검토) |
| 시대 길이 | 시대당 2시간, 3시대 총 6시간 |
| 투자금 | 시대가 바뀌어도 계속 이월. 늘리는 수단은 인형 눈 붙이기·결제·광고 보상 (엔진은 입금 함수만) |

### 기술 구조
- 타입스크립트 + Vite, 테스트는 Vitest. 화면은 나중에 Phaser, 앱 포장은 Capacitor를 검토한다.
- **게임 규칙 엔진은 화면과 완전히 분리**한다. 엔진은 시계·화면·인터넷을 쓰지 않고, 화면 쪽 타이머가 5초마다 `advanceTick()`을 부른다 (테스트로 강제).
- 같은 시드(출발 숫자)면 뉴스·가격이 항상 똑같이 나온다. 세이브와 데이터 분석이 이 성질을 이용한다.

## 2. 한 판(시대)의 흐름

1. **시대 시작**: 테마 풀 36개 중 20개를 추첨한다. 종목은 테마당 1개이고 모두 1,000코인에서 시작한다.
2. **2시간 동안 실시간 진행**: 5초가 1틱이고, 시대당 1,440틱이다. 뉴스가 떠도 시간은 멈추지 않는다(튜토리얼만 예외).
3. **뉴스**: 첫 뉴스는 1~3분 뒤, 그 뒤로 4~7분 간격으로 나온다. 시대당 평균 약 22개다.
4. **해설 알림**: 뉴스 발표 120초 뒤, 실제로 많이 움직인 종목 3개와 이유를 보여준다.
5. **시대 종료**: 가진 종목을 모두 자동으로 팔고(청산) 수익률을 정산한다. 남은 돈은 다음 시대로 이월한다.

## 3. 확정된 규칙

### 3.1 가격

| 항목 | 값 |
|---|---|
| 평소 변동 | 틱마다 -1.5% ~ +1.5% (0.1% 단위) |
| 1분 한도 | 12틱 누적 ±3%. 넘치면 넘친 만큼 반대로 튕긴다(반사) |
| 뉴스 사이 한도 | 뉴스 발표 순간 가격(P0) 기준, 다음 뉴스 전까지 0.7×P0 ~ 1.3×P0 |
| 가격 | 정수, 최소 1코인 |
| 차트 | 최근 20분(240개) |

### 3.2 뉴스 반영

| 항목 | 값 |
|---|---|
| 반영률 | 영향도 × 3% × 배율. 결과는 ±30%로 자른다 |
| 배율 | 연결 강도 3: 0.6~1.4 / 강도 2·1: 0.4~1.6 (영향마다 무작위) |
| 반영 시점 | **발표 순간 75%**, **5초 뒤 나머지 25%** |
| 관성 | 반영 뒤 2틱(10초): 같은 방향 50% / 반대 25% / 변동 없음 25%, 크기 0.1~1.5% |

> 발표 순간 75% 반영은 이번 보완에서 추가했다. 이전 규칙(전부 5초 뒤)은 뉴스를 보고 5초 안에 사면 시대당 +500% 넘게 벌 수 있는 허점이 있었다. 설정 하나로 이전 규칙으로 되돌릴 수 있다.

### 3.3 뉴스 종류와 일정

| 종류 | 설명 | 규모(magnitude) |
|---|---|---|
| 속보 (breaking) | 예고 없이 나오는 단독 뉴스 | 3~9 |
| 잠정 (tentative) | 아직 확정되지 않은 소식. 스토리의 시작 | 1~3 |
| 결과 (outcome) | 잠정 뉴스의 결말. 스토리마다 서로 반대인 2개를 준비 | 7~9 |
| 단서 (clue) | 잠정과 결과 사이에 나오는 후속 뉴스 (선택) | — |

- 빈 뉴스 자리마다, 진행 중인 스토리가 없으면 85% 확률로 새 잠정 뉴스를 시작하고, 아니면 속보를 넣는다. 결과적으로 속보·잠정·결과가 각각 약 1/3이다.
- 결과 뉴스는 잠정 뉴스 뒤 **15분 안**에 나온다. 동시에 진행되는 스토리는 1개, 시대 종료 15분 전부터는 새 잠정 뉴스를 시작하지 않는다.
- 결과는 그때그때 추첨한다. **잠정 뉴스의 단서대로 65%**, 반대로 35%다. 한 판에 같은 스토리는 한 번뿐이라, 확신보다 분산 투자를 고르게 하려는 의도다.
- 실제 역사와 다른 결과는 화면에 "가상 시나리오" 태그를 붙인다.
- 같은 뉴스는 한 시대에 다시 나오지 않는다.

### 3.4 테마 추첨

| 항목 | 값 |
|---|---|
| 풀 | 시대마다 36개: 주요(core) 24 / 배경(peripheral) 12, 긍정 13 / 부정 13 / 중립 10 |
| 활성 | 20개: 긍정 7 / 부정 7 / 중립 6, core 11개 이상 |
| 통과 조건 | 이번 판에 쓸 수 있는 속보 10개·스토리 8개 이상 (최대 50번 다시 추첨) |
| 결과 | 3번 안에 99.8% 통과 (가상 데이터 1,000판) |

### 3.5 계좌

| 항목 | 값 |
|---|---|
| 시작 자금 | 10,000코인 |
| 매매 | 현재가로만, 정수 주 단위 |
| 수수료 | 매수·매도 각 0.2% (내림, 매입원가에 포함) |
| 수익률 | **시대별 시간가중수익률**: 입금 때마다 구간을 나눠 구간 수익률을 곱한다 (입금이 수익으로 잡히지 않음). 정산·랭킹 모두 이 값. 누적 = 시대별 수익률의 곱 |
| 입금 | `deposit(금액, 출처)`: 인형 눈 붙이기 / 결제 / 광고 보상 / 기타. 결제·광고 SDK는 앱 쪽 |
| 관심 종목 | 사면 자동 추가, 목록 맨 위 정렬 |
| 색상 | 오르면 빨강/내리면 파랑 (설정에서 바꿀 수 있음) |

### 3.6 튜토리얼
- 첫 진입 때 한 번만 하고, 설정에서 다시 볼 수 있다.
- 5분짜리 판: 뉴스 1개 → (시간 정지) 매수 → 반영 확인 → 해설 알림.
- 뉴스가 뜨는 순간 75%가 먼저 반영되므로, "읽고 따라 사기보다 미리 공부하는 쪽이 유리하다"를 직접 보여 준다.

### 3.7 세이브
- 담는 것: 튜토리얼 완료·기록 동의 여부, 시드, 시대 순번, 그 시대 시작 자금, 추첨 결과, 지난 시대 수익률, **이번 시대 행동(매매·입금)**, **엔진·콘텐츠·밸런스 버전**, **상태 스냅샷(틱, 종목 현재가, 계좌·보유 종목, 즐겨찾기)**.
- 저장 빈도: 매매·입금·뉴스 발표·백그라운드 전환·30초마다·시대 종료 → 강제 종료 후 되돌아가는 시간이 최대 30초.
- 불러오기: 버전이 같으면 행동을 리플레이해 **그대로 이어서**(`resumed`). 다르면 스냅샷 가격으로 그 시대를 자동 정산하고 다음 시대부터 새 버전(`settled_on_version_change`). 이미 본 뉴스를 알고 다시 하거나 손해 본 시대를 지울 수 없다.

### 3.7-1 정보 숨김
- 화면은 공개용 뷰(`PublicGame`)만 받는다. 플레이 중 **모든 뉴스의 호재/악재 방향, 테마 분위기·비중을 보여주지 않는다**.
- 종목 목록은 즐겨찾기 먼저 + 가나다순, 종목·뉴스 id는 판마다 바뀌는 무작위 문자열.
- 시대가 끝난 뒤 `getEraDebrief()`로 분위기·비중, 단서와 실제 결과, 역사 여부, 해설 전체를 공개한다 (사후 학습).
- 화면 단계에서 지킬 것: `docs/ui_handoff.md`.

### 3.8 기본으로 꺼 두는 옵션

| 옵션 | 판단 |
|---|---|
| 주문 지연 (`ORDER_DELAY_TICKS`) | 발표 즉시 반영으로 필요 없어짐 |
| 간접 영향 늦게 반영 (`INDIRECT_EXTRA_DELAY_TICKS`) | 켜면 반영 뒤에 사도 이익이 나는 허점(+29%) → 켜지 않는다 |

## 4. 밸런스

### 4.1 목표와 현재 결과
가상 시대 데이터 5개 × 시드 200판, 전략별 시대당 수익률 **중앙값의 평균**이다. 수수료 포함. 단서 확률 65%.
† = 방향(호재/악재·분위기·단서)을 정확히 아는 전략 → 사람이 본문을 읽고 해석해서 얻을 수 있는 이득의 이론상 상한.

| 전략 | 설명 | 목표 | 결과 | 손실 확률 | 큰 손실(<-50%) |
|---|---|---|---|---|---|
| 무작위 매매 | 1분마다 아무거나 사고팖 | -10 ~ +5% | -6.0% ✅ | 72% | 0% |
| 균등 매수 후 보유 | 처음에 고르게 사서 끝까지 | -10 ~ +20% | -2.6% ✅ | 60% | 0% |
| 지연 추종† | 뉴스 반영 뒤 호재 종목을 삼 | -5 ~ +15% | -1.0% ✅ | 52% | 1% |
| 초고속 추종† | 뉴스가 뜨자마자 호재 종목을 삼 | +30 ~ +80% | +62.7% ✅ | 5% | 0% |
| 분위기 전략† | 긍정 분위기 테마만 사서 보유 | +5 ~ +40% | +11.1% ✅ | 19% | 0% |
| 역분위기† | 부정 분위기 테마만 사서 보유 | -40 ~ -5% | -15.5% ✅ | 91% | 0% |
| 잠정 정방향† | 잠정 뉴스의 단서대로 미리 삼 | **+25 ~ +100%** | +33.9% ✅ | 25% | 1% |
| 잠정 역방향† | 단서 반대로 삼 | 0% 미만 | -41.3% ✅ | 91% | 34% |
| 잠정 몰빵† | 잠정 뉴스마다 전액을 영향이 가장 큰 1종목에 | (참고) | +39.0% | 26% | 3.2% |
| 잠정 분산† | 잠정 뉴스마다 가용 자금 20~30%를 3종목에 | (참고) | +8.8% | 21% | 0.0% |

- 분산 점검: 분산의 중앙값이 양수이고 큰 손실 확률이 몰빵의 절반 이하 → 기대대로.
- 3시대 연속 이월: 자산이 1,000코인 아래로 떨어진 판은 잠정 역방향(8.5%)에서만 나왔다.

**의도한 순서**: 단서를 읽는 공부 ≥ 빠른 반응 > 시대 분위기 파악 > 뉴스 뒤따르기 ≈ 무작정 보유 > 무작위

### 4.2 지금까지 바꾼 설정

| 설정 | 값 | 이유 |
|---|---|---|
| 뉴스 반영 | 기존 5초 뒤 100% → **발표 즉시 75% + 5초 뒤 25%** (승인) | 초고속 추종 +536% → +63% |
| 단서대로 나올 확률 | **65%** (기획 결정) | 분산 투자 유도. 잠정 정방향 목표 +25~100%로 조정 |
| 분위기 편향(콘텐츠 가이드) | 65% → **75%** | 분위기 전략이 목표 미달 |
| 수익률 | 단순 수익률 → **시간가중수익률** | 입금이 수익으로 잡히지 않게 |

### 4.3 주의점
- 판마다 편차가 크다. 예를 들어 지연 추종은 하위 10%가 -31%, 상위 10%가 +48%다. 실력보다 운이 크게 느껴질 수 있다.
- 분위기 전략과 잠정 정방향은 데이터에 따라 목표 하한 근처까지 내려간다. 단계 B 실제 데이터로 다시 확인한다.
- 지금 수치는 **가상 데이터와 봇**의 결과다. 사람은 다르게 놀기 때문에 실제 플레이 기록으로 다시 맞춰야 한다 (6장).

## 5. 콘텐츠 작성 기준 (단계 B부터 적용)

### 5.1 테마·종목
- 테마마다 핵심 단어 5~8개와 "그 시대에 존재했다"는 근거 한 줄을 적는다(모르면 "확인 필요").
- 종목명은 **가상**이다. 실존 기업명·상표·인물명은 쓰지 않는다 (테스트로 금지 단어 검사).
- 종목명 형식: **"2글자 중립 수식어 + 업종"** (예: 평화 방산, 온유 제약). 업종 뒤 '주' 금지. 색·사물·자연물 같은 중립 단어를 쓰고, 평가·전망 어감(최강, 폭등, 유망, 위기, 호황, 불황 등)은 금지.
- 기업 설명은 3줄 안팎, 제품·서비스 중심의 중립 서술 (전망·평가 표현 금지).

### 5.2 뉴스
- 뉴스마다 영향 테마 6~9개, 호재와 악재를 섞는다.
- 영향도 공식: `|영향도| = max(1, 반올림(규모 × 계수))`. 계수는 연결 강도 3(직접) 1.0 / 2(밀접) 0.6 / 1(간접) 0.3이다.
- 연결 강도 3은 뉴스 단어가 테마 핵심 단어와 일치해야 하고, 강도 2·1은 연결 설명(chain)을 쓴다.
- 영향이 큰 상위 4개 항목은 해설용 한 줄 이유를 꼭 쓴다(한국어 필수).
- **분위기 편향 75%**: 긍정 테마는 75% 정도 호재, 부정 테마는 75% 정도 악재, 중립은 반반.
- 배경(peripheral) 테마도 뉴스 풀 전체에서 최소 2번은 영향을 받아야 한다.
- 본문은 신문 기사처럼 2~3줄이고, **연도·월 표기는 금지**한다(시대 안에서 무작위 순서로 나오므로).
- 제목·본문에 **주가 방향을 직접 알려주는 표현 금지**: 호재, 악재, 수혜, 수혜주, 타격주, 상승 예상, 하락 예상 (사건 자체의 "유가 급등"은 괜찮다).

### 5.3 스토리
- 잠정 뉴스 1개 + 서로 반대인 결과 2개(공통 테마의 방향이 반대) + 단서(선택).
- 잠정 뉴스 본문은 결과를 확정처럼 쓰지 않고, 어느 쪽으로 기우는지 단서가 읽히게 쓴다.
- **추천: 단서가 가리키는 결과 = 실제 역사.** 역사를 공부한 사람과 단서를 읽은 사람이 같은 쪽에 서게 되어 교육 목적과 맞는다.
- 결과가 예상과 반대로 반응한 실제 기록이 있으면 그 해설(reactionNote)을 쓴다.

### 5.4 양
- 시대당 테마 36개 + 종목 36개, 속보 12개 이상, 스토리 약 10개 (단계 B 목표).
- 반복 플레이를 생각하면 나중에는 **속보 20개 이상, 스토리 12개 이상**이 필요하다.

### 5.5 점검
- `npm run lint:content`로 위 기준을 자동 점검한다.
- 실제 사건 근거는 `docs/2000s_fact_check.md`에 팩트체크 표로 남긴다.

## 6. 플레이 데이터 수집 계획

### 6.1 원칙
- 가격은 시드로 다시 계산할 수 있으므로 **플레이어의 선택만** 기록한다. 한 시대(2시간)에 압축 후 약 5~11KB다.
- 엔진은 기록만 내보내고, 저장·전송은 앱이 맡는다.
- 동의한 사람만 수집하고, 개인 정보(이름·이메일·위치·광고 ID)는 모으지 않는다. 플레이어 구분은 무작위 설치 id만 쓴다.

### 6.2 무엇을 기록하나
- **게임이 자동으로 남기는 것(12종)**: 판 시작, 테마 추첨 결과, 뉴스 발표·반영, 해설 알림, 매매, 거부된 주문, 관심 종목, 일시정지·재개, 1분마다 자산, 정산.
- **매매 순간의 상황**: 최근 뉴스 뒤 몇 틱이었나, 이 종목이 그 뉴스와 어떻게 엮였나, 진행 중인 스토리의 단서를 따랐나, 최근 가격 흐름, 매매 직전 자산.
- **화면이 남기는 것(9종)**: 뉴스 팝업을 본 시간, 관련 테마 누름, 화면별 체류 시간, 해설 열람, 주문 창을 열었다가 그냥 닫음, 설정 변경, 튜토리얼 단계, 오류.

### 6.3 기록으로 무엇을 조정하나 (예시)

| 보는 지표 | 벗어나면 조정할 것 |
|---|---|
| 뉴스 뒤 첫 매수까지 걸린 시간 | 발표 즉시 반영 몫(75%) |
| 단서를 읽는 플레이어의 수익 | 단서 확률(65%), 잠정 뉴스 문장 |
| 뉴스별 "방향 맞게 매매한 비율" | 헷갈리는 뉴스의 본문·연결 강도 수정 |
| 뉴스 팝업을 본 시간 | 본문 길이, 팝업 디자인 |
| 중간에 그만둔 시점 | 시대 길이, 뉴스 간격 |
| 다음 시대 시작 자금이 아주 적은 비율 | 최소 자금 보조 여부 |

### 6.4 사람과 봇을 같은 잣대로 비교
- 기록을 분석해 플레이어를 행동 유형으로 나눈다: 뉴스 즉시 반응형, 뉴스 추종형, 단서 읽기형, 단서 반대형, 보유형, 잦은 매매형, 거의 안 함.
- 같은 분석을 시뮬레이션 봇 기록에도 돌려 비교한다(봇 기록으로 시험 시 모든 봇의 유형을 정확히 맞힘).
- 실제 사람의 행동 수치(반응 속도 분포, 몰빵 정도)를 봇에 넣어 "사람형 봇"으로 다시 시뮬레이션한다.

### 6.5 단계

| 단계 | 시점 | 할 일 |
|---|---|---|
| 0 | W1 (완료) | 기록 형식, 엔진 자동 기록, 리플레이, 분석 함수, 리포트 |
| 1 | W2 화면 | 화면 기록 연결, 기기 저장, 테스터용 "기록 내보내기" (서버 없음) |
| 2 | 소규모 베타 | 수집 동의 화면, 간단한 업로드 서버, 일일 리포트 |
