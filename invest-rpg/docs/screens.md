# 화면 구성 (1인칭 4탭)

> **2026-10-10: 화면 배치·색·문구는 `docs/DESIGN_HANDOFF.md`(도트 시안)로 바뀌었다.** 아래는 탭 구조·규칙의 옛 설명이라 숫자·색·배치는 맞지 않을 수 있다.

> 걷는 맵·캐릭터·이동 조작은 없다. 하단 탭 4개로 1인칭 화면을 오간다. 캐릭터는 화면에 나오지 않는다.
> 그림은 모두 2D 픽셀, 어둡고 차분한(저채도) 분위기. 시대마다 디자인이 바뀐다 (`src/data/eraTheme.json`).
> 엔진 쪽 규칙(데이터): `src/engine/homeActivities.ts`(탭 레지스트리). 화면 단계에서 지킬 것: `docs/ui_handoff.md`.

## 1. 탭

| 순서 | 탭 | id | 1차 출시 | 상단 왼쪽 | 상단 오른쪽 | 화면 안 |
|---|---|---|---|---|---|---|
| 1 | 거실 | `living_room` | 활성 | `NEWS!`(안 읽은 뉴스) | 보유 현금 코인, (2배속이면) x2 | LP 플레이어, 강아지 |
| 2 | 주식창 | `trading` | 활성 | — | — | 계좌 바(총 자산·손익률·남은 시간·1배/2배), 종목 목록, 주문 패널, 뉴스 피드 |
| 3 | 작업실 | `workshop` | 활성 | `NEWS!` | 보유 현금 코인, 정산 예정 작업 수입, x2 | 책상 위 인형 (눈 붙이기) |
| 4 | TV홈쇼핑 | `tv_shopping` | **비활성** | `NEWS!` | 보유 현금 코인, x2 | 시대별 TV + "방송 준비 중" 노이즈 화면 |

- 켜기/끄기: `TAB_ENABLED`(빌드 설정) 한 곳. TV홈쇼핑을 켤 때는 이것만 바꾼다.
- 시대 시작 때 기본 탭은 **주식창**(새 종목 확인 유도), 그 외에는 마지막으로 보던 탭.
- 주식창에 들어가면 뉴스·리포트를 모두 읽음 처리 → `NEWS!`가 사라진다. 주식창에 있는 동안 온 뉴스도 바로 읽음.
- `NEWS!`는 **뉴스에만** 켜진다. 주가 리포트는 피드 안의 강조 표시만.
- 보유 현금(오른쪽 위)은 작업 중에 늘지 않는다 (작업 수입은 시대 종료 때 합산). 작업실만 "정산 예정 작업 수입"을 따로 보여준다.
- 배속(1배/2배)은 주식창 계좌 바에서 고르고, **탭을 옮겨도 유지**된다(`SPEED_RESETS_ON_TAB_LEAVE=false`). 2배면 다른 탭 상단에 작은 "x2".

## 2. 거실

- 시대별 배경(`livingRoomVariant`), **LP 플레이어**, **강아지 한 마리**.
- LP 터치: 재즈 → 클래식 → 힙합 → 락 → 재즈 순환 (`MusicPlayer.cycleGenre()`), LP 회전 애니메이션, 장르 이름 토스트. 끄기 없음 (음소거·볼륨은 설정).
- 첫 터치 전에는 소리를 낼 수 없다 (휴대폰 브라우저 규칙) → 첫 터치에서 `unlock()`.
- 강아지 터치: 매번 쓰다듬기 효과, **3번째 터치마다** 꼬리 흔들기 / 잔상 좌우 흔들림 / 하트 / 귀 쫑긋 중 하나 (직전과 같은 반응 연속 금지). 시대별 단계: 2000년대 강아지(활발), 2010년대 성견, 2020년대 노견(느리고 부드럽게).

## 3. 주식창 (HTS 스타일)

익숙한 회색 HTS 창 느낌을 픽셀로 (입체 테두리, 각진 버튼, 선명한 경계, 톤은 낮게). 시대별 색 세트 `htsSkin`.
위에서 아래로:
1. **계좌 바**: 총 자산, 손익률(이번 시대 시간가중수익률), 남은 시대 시간, 배속 선택(1배 / 2배 나란히, 하나만 켜짐)
2. **종목 목록**: 6~7개 보이고 스크롤. 열 = 즐겨찾기 별 · 종목명 · 현재가 · 등락률(시대 시작가 대비). 즐겨찾기 먼저, 그 안팎은 가나다순. 가격이 바뀌면 칸이 잠깐 번쩍
3. **주문 패널**(종목을 누르면): 종목명·현재가·등락률, 최근 20분 미니 차트(접기), 기업 설명 1~2줄, 보유 수량·평균 매수가, 수량(+/−)과 '최대', 매수/매도. 확인 창 없이 바로 체결 + 짧은 안내
4. **뉴스 영역(피드)**: 최신 뉴스(제목+본문)를 펼쳐 보여주고, 발표 120초 뒤 **그 뉴스 바로 아래에 '주가 리포트' 행**(종목별 1~2줄, 최대 3개 + "외 N종목")이 붙는다. 이전 뉴스는 제목 한 줄로 접고, 누르면 리포트까지 펼친다. **호재/악재 방향 표시 없음. 시간을 멈추는 창 없음.**

## 4. 작업실

- 책상 위 인형. 터치마다 눈 하나 → 눈 둘 → 완성(옆으로 빠지고 눈 없는 인형이 들어옴).
- 완성하면 "+3"이 **정산 예정 작업 수입** 카운터로 날아가 숫자가 는다. "작업 수입은 시대가 끝날 때 한꺼번에 지급돼요" 안내.
- 2터치까지는 보상 없음. 화면 어디를 눌러도 인식. 초당 6터치를 넘는 터치는 무시.
- 작업 화면이 열려 있어도 게임 시간은 흐른다.

## 5. TV홈쇼핑 (1차 비활성)

- 시대별 TV(`tvVariant`: CRT / 평면 / 대형 평면) 위에 "방송 준비 중" 노이즈 프레임. 터치해도 아무 일 없음.

## 6. 창 (탭 위에 뜨는 것)

| 창 | 언제 | 내용 |
|---|---|---|
| 시대 종료 정산 | 시대가 끝나면 | **투자 결과(코인·수익률) + 작업 수입 = 합계**, '확인' → 다음 시대 (마지막이면 최종 요약). 접힌 "돌아보기"(`getEraDebrief()`) |
| 최종 요약 | 마지막 시대 정산 뒤 | 시대별 투자 수익률, 작업 수입, 최종 총 코인 |
| 설정 | 설정 버튼 | 언어, 상승 색상 모드, 볼륨(마스터·음악·효과음), 음소거, 음악 저작권 표시, 플레이 기록 동의 |
| 시대 시작 안내 | 시대 시작 | "처음 7분은 뉴스가 없어요" (`era.graceNotice`) |

## 8. 구현 (단계 U)

- 코드: `src/ui/` (바닐라 TypeScript + Vite). 켜기: `npm run dev`, 스크린샷: `npm run shots`.
- **설정 버튼: 상단 바 가운데** (모든 탭 같은 자리). 왼쪽 위 `NEWS!`, 오른쪽 위 코인과 겹치지 않고, 엄지가 자주 닿는 아래쪽과 멀다. 주식창에서는 계좌 바 가운데.
- 그림 배율: 기준 180×320의 정수 배율 (360×640·390×844 모두 2배). 상단 바·탭 바 높이는 기준 픽셀 20·32에 맞춘다 (`docs/art_spec.md`).
- 화면 로직(무엇을 어떤 글자로 보여줄지)은 `src/ui/viewModels.ts`의 순수 함수 → `tests/ui.test.ts`.
