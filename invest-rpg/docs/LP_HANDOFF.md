# LP 플레이어 (레벨별 3단계) 전달

## 파일
- `lp/{worn|clean|walnut}/{2000s|2010s|2020s}_{day|night}/{idle|play0|play1|play2|play3}.png`
  - 투명 PNG, **44×64**, 도트 1칸 = 1px (게임이 ×3). 총 90장
  - `idle` 정지(톤암 대기) · `play0~3` 재생 4프레임(톤암 내려옴, LED, LP판 회전 점, 음표 떠오름) — 약 8~10fps로 반복
- `lp_sheet.jpg` — 확인용 시트 / `ref_code/gLP.py` — 생성 코드(참고용)

## 레벨별 사용
| 방 레벨 | tier | 설명 | 스프라이트 왼쪽 위 좌표(씬 130×281 기준) |
|---|---|---|---|
| Lv0~2 | `worn` | 낡은 가방형 레코드 플레이어 (긁힘·테이프·모서리 보호대), 박스 위 | (5, 91) |
| Lv3~5 | `clean` | 같은 가방형, 깨끗한 상태, 서랍장 위 | (9, 94) |
| Lv6~7 | `walnut` | 월넛 턴테이블 + 유리 덮개 | (9, 94) |

- 바닥 접지선(스프라이트 y=61)이 박스 윗면(y=152) / 서랍장 윗면(y=155)에 닿도록 배치한 값입니다.
- 폭은 모두 36px(스프라이트 x=4~39) — 박스·서랍장 위에서 삐져나오지 않습니다.
- 시대/낮밤 별로 LP 라벨 색·재질 톤만 다릅니다(위 폴더 구조). 유리 덮개는 반투명 알파입니다.
- LP를 터치하면 `idle` ↔ `play*` 전환, 음악 변경 동작은 기존과 동일하게 연결하면 됩니다.
