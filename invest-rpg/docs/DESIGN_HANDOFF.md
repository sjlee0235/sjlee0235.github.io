> 이 문서는 **그림·색·글꼴·화면 배치·문구**의 기준이다. `GAME_DESIGN.md`(동작·경제 규칙)와 함께 읽고, **둘이 다르면 이 문서가 우선**한다 (다른 점은 12장 표).
> 함께 받은 파일: 화면 시안 JPG(`screen_*.jpg`), **인테리어 단계 시트**(`interior_levels_*.jpg`), 강아지 동작(`dog_poses_sheet.jpg`, `dog_motion_map.jpg`, **`dog_touch_reactions.jpg`**), 가이드(`guide.jpg`), 그리고 `handoff_assets.zip`(원본 도트 PNG·강아지 스프라이트·정적 참고 HTML·그림 생성 코드).
> **이번 개정에서 추가된 것**: 인테리어 7단계(16장), 강아지 터치 반응(17장), TV 홈쇼핑 탭 화면, 거실 위쪽 **인테리어 업그레이드 버튼**(LP 안내 문구는 삭제). 가정은 18장.

> **2026-10-10 구현 반영 메모**: 이 문서를 그대로 구현하되 다음은 기획 결정(GAME_DESIGN 5차 결정)에 따라 바꿨다 — 인테리어 **단계당 2,000코인**(합계 14,000, 시대 이월), 작업 수입은 **밤 12시 대신 인형 100개를 완성하면 바로 지급**(지급 뒤 지급 예정 +0·완성 0개), 작업실 안내 문구 **"인형 100개를 완성하면 보상이 지급돼요"**, 작업 인형 가슴 무늬는 **분홍 하트**. 13장(밤 12시 지급 가정)은 이 결정으로 대체되었다.

## 3. 그림체 규칙 (모든 그림에 공통)

1. **외곽선**: 모든 물체에 1도트 두께. 색은 밤 `#0c0818`, 낮 `#2a1a30` (장면 그림 안에서는 밤 `#0c0818`, 낮 `#2a1a30`).
2. **면**: 한 물체 = 단색 한 가지. 번지는 그림자·그라데이션·점 찍기(디더링) 금지.
3. **입체**: 위쪽·왼쪽 가장자리 1도트는 밝게(흰색 30% 섞음), 아래쪽·오른쪽 가장자리 1도트는 어둡게(검정 22% + 보라 12% 섞음).
4. **빛**: 부드러운 그라데이션 대신 **경계가 딱 떨어지는 띠**로. 밤은 램프 불빛 웅덩이(띠 3겹)와 달빛 자국, 낮은 창틀 그림자가 든 햇빛 자국.
5. **확대**: 항상 정수 배, 최근접(nearest). 그림을 부드럽게 줄이거나 늘리지 않는다.
6. **작은 물체는 단순하게**: 눈은 2×3(어른/노견)·3×3(아기) 도트에 흰 하이라이트 1점, 코 3×2, 입은 선 1줄.
7. **인테리어 단계 색**: 단계가 낮을수록 가구·벽·바닥 색의 채도를 빼고 때(어두운 갈색)를 섞는다 (16.1). 소품 색(컵라면·종이·상자)은 밤에 `#20184a`를 42% 섞어 어둡게.

### 8.2 움직임 (거실, 상태 머신)
강아지는 한 자리에 있지 않고 **돌아다닌다.** 아래 상태를 이어 붙인다 (`dog_motion_map.jpg` 참고).

| 상태 | 스프라이트 | 설명 |
|---|---|---|
| `LIE_RUG` | lie | 러그 위 엎드려 쉼 (기본, 시작 상태) |
| `SIT_FLOOR` | sit | 바닥에서 앉아 두리번 (좌우 반전 가능) |
| `SIT_SOFA` | sit | 소파 좌석 위에 앉음 (발 y 172, 왼쪽 x 74~, **좌우 반전 = 방 쪽을 봄**) |
| `WALK` | walk0 ↔ walk1 | 바닥을 걸어 목적지로 이동, 방향에 따라 반전 |
| `JUMP_UP` / `JUMP_DOWN` | walk0 | 바닥 ↔ 소파를 **포물선**으로 이동 (0.6초, 꼭짓점 14도트 위) |

- **전이**: `WALK`로 새 목적지 → 도착 → `LIE_RUG` / `SIT_FLOOR` / (소파 앞이면) `JUMP_UP`→`SIT_SOFA` 중 무작위 → **쉬는 시간 3~9초**(노견은 ÷0.6, 아기는 ÷1.3) → 다시 `WALK`. `SIT_SOFA`에서 쉬고 나면 `JUMP_DOWN` 후 `WALK`.
- **속도**: 걷기 초당 약 12도트 × 시대 배수(아기 1.3 / 어른 1.0 / 노견 0.6). 걷기 프레임 교체 0.2초 ÷ 배수.
- **걸을 수 있는 범위**: 발 y **200~262**, 스프라이트 왼쪽 x **0~88** (130 폭 안). 소파 앞 점프 출발 구간은 발 y 200~214, 왼쪽 x 60~90.
- **겹침 순서**: 가구 → 강아지 순으로 그린다. 소파 위에 앉으면 등받이 방석 앞에 보이게. 신문 더미(x 12~39, y 216~236) 앞은 지나가도 된다.
- **숨쉬기**: 앉기·엎드리기 중에는 스프라이트를 **0.8초마다 위아래 1도트** 움직여 숨쉬는 느낌을 낸다 (별도 프레임 없음).
- **터치**: 강아지를 누르면 **17장의 터치 반응**이 이동·쉬기 상태보다 우선한다 (1번 터치 = 서서 웃기, 5번 연속 = 배 까고 눕기). 반응이 끝나면 이전 상태(걷기·앉기 등)로 돌아간다.
- 연출 난수는 시장 난수와 분리 (13.2 규칙 그대로).

  3. **본문 3줄 이내** (12, 줄간격 1.45, `mute` 색, 3줄에서 `…` 잘림)
  4. 주가 리포트 상자 (발표 120초 뒤부터): "주가 리포트" 11/600 → 종목 `{이름} {합계%}`(13/700, 상승 빨강·하락 파랑) + 이유(12) → 세부 "발표 즉시 ○% · 5초 뒤 ○%"(11)

## 14. 구현 메모

- **이미지 확대**: `image-rendering: pixelated`, 정수 배만. 장면 PNG는 130×281 → CSS 390×(843→844).
- **글꼴**: Google Fonts `IBM Plex Sans KR` 400/500/600/700. 앱 포장(오프라인)에서는 폰트 파일을 앱에 넣는다. 숫자는 항상 `tabular-nums`.
- **아이콘**: 위 격자를 `<svg shape-rendering="crispEdges">` 사각형으로 그리거나 PNG 스프라이트로 구워 쓴다. 격자 하나가 화면 픽셀 정수 배(2배)가 되도록 크기를 맞춘다.
- **밤/낮 전환**: CSS 변수(토큰 9장) + 배경 이미지 2장을 겹쳐 두고 불투명도 2초 전환.
- **파일명 제안** (`artManifest.json`): `living_{era}_{night|day}_lv{0..7}.png`, `workshop_{era}_{night|day}_lv{0..7}.png`, `tv_{era}_{night|day}_lv{0..7}.png`, `dog/{pup|adult|old}_{lie|sit|walk0|walk1|happy0|happy1|belly0|belly1}.png`, `dog/hearts_{0|1|2}.png`.
- **인테리어 단계 전환**: 배경 PNG를 새 단계로 바꿀 때 0.4초 크로스페이드. 시간대 전환(2초)과 같은 방식으로 이미지 두 장을 겹쳐 불투명도만 바꾼다.
- **확인 방법**: `ui_reference/*.html`을 브라우저 폭 390으로 열어 시안과 비교. 구현한 화면과 같은 폭으로 스크린샷을 찍어 나란히 본다.

## 17. 강아지 터치 반응 (기획서 13.2를 대체)

| 터치 | 상태 | 스프라이트 | 설명 |
|---|---|---|---|
| **1번 터치** | `HAPPY` | `{stage}_happy0` ↔ `happy1` (0.25초마다 번갈아) | **그 자리에 멈춰 서서 웃으며 꼬리를 흔든다.** 2.5초 뒤 이전 상태로 돌아감 (걷기·앉기·엎드리기 중 어떤 상태든 바닥에 선 모습으로 바뀜) |
| **5번 연속 터치** | `BELLY` | `{stage}_belly0` ↔ `belly1` (0.3초마다) + `hearts_0 → 1 → 2` (0.4초마다 순환) | **배를 까고 드러누워 꼬리를 흔들고, 몸통 주위로 하트가 올라온다.** 4초 뒤 이전 상태로 돌아감 |
- **연속 판정**: 직전 터치와의 간격이 **1.5초 이내**면 연속(횟수 +1), 넘으면 1부터 다시. 5번째 터치에서 `BELLY`로 바뀌고 횟수는 0으로 초기화. `BELLY` 중에는 터치를 세지 않는다 (끝난 뒤부터 다시).
- **하트 오버레이**: `hearts_*.png`는 48×40, 강아지 스프라이트(42×40)와 **같은 기준점**에 그린다 (하트는 몸 위·앞뒤에만 있어 안 겹침). 강아지가 왼쪽을 볼 때(좌우 반전)는 오버레이도 반전하고 x를 6도트 왼쪽으로 옮긴다.
- **발 위치**: `happy*`·`belly*` 모두 발바닥/등 선이 다른 동작과 같은 맨 아래 줄이라 **"발 닿는 y"를 그대로 쓰면 된다** (8.1).
- **소파 위**에서 눌렀을 때: 먼저 `JUMP_DOWN`(0.6초)으로 바닥에 내려온 뒤 같은 규칙으로 반응한다 (소파 위 웃기·배 까기 그림은 없음).
- 이동 중에 눌러도 그 자리에 바로 멈춘다. 반응 중에는 걷기·쉬기 타이머를 멈추고, 끝나면 **쉬는 시간 3~9초부터** 다시 시작.
- 연출 난수는 시장 난수와 분리 (기획서 13.2). 플레이 기록에는 `dog_touch`(횟수)와 `dog_belly` 이벤트를 남긴다.

## 18. 인테리어·터치 — 구현에 필요한 가정 (확정 필요: 기획서 D8)

1. **단계는 저장된다**(세이브에 `interiorLevel` 0~7). 시대가 바뀌어도(2000s→2010s→2020s) **단계는 유지**되고 시대 팔레트·강아지 나이만 바뀐다.
2. **비용은 보유 현금에서** 낸다 (평가금액 아님). 투자 수익률 계산에서는 **출금처럼 처리**: 구매 순간 시간가중수익률 구간을 나누고 손실로 세지 않는다 (작업 수입 입금과 반대 방향).
3. **확인 창 없음** (한 번 누르면 구매). 되돌리기 없음.
4. 단계당 2,000이라 **시작 자금(10,000)으로는 5단계까지** 살 수 있어, 서둘러 사면 투자 자금이 줄어든다. 의도한 선택 요소이긴 한데 **밸런스 확인 필요** (작업 수입이 인테리어 값을 대는 흐름이 되는지).
5. 코인이 모자라면 버튼 55% 불투명 + "코인이 부족해요" 토스트.
6. 세 화면(거실·작업실·TV)은 항상 같은 단계. TV 모양은 지금 전 시대 브라운관.
7. 플레이 기록: `interior_upgrade`(새 단계, 시각, 그때 코인).
