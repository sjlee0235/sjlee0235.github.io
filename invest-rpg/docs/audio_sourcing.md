# 음악 구하기 체크리스트 (거실 LP)

> 곡은 기획자가 **직접** 구해서 넣는다. 개발 쪽에서 곡을 내려받거나 AI로 만들지 않는다.
> 아래 표의 조건은 개발 쪽이 아는 범위의 요약이다. **확실하지 않은 것은 "확인 필요"**로 표시했고, 최종 약관은 기획자가 직접 확인한다. (법률 자문 아님)

---

## 1. 무엇이 필요한가

| 장르 (LP 순서) | 곡 수 | 느낌 (대중적이고 익숙한 인스트루멘탈) |
|---|---|---|
| 재즈 | 2~3곡 | 라운지 재즈 (피아노·색소폰, 잔잔한 템포) |
| 클래식 | 2~3곡 | 널리 알려진 레퍼토리(예: 바흐·쇼팽·드뷔시 소품)의 **퍼블릭 도메인 녹음** |
| 힙합 | 2~3곡 | 로파이 힙합 비트 (가사 없음) |
| 락 | 2~3곡 | 인스트루멘탈 락 (기타 중심, 가사 없음) |

- 형식: **mp3 또는 m4a(AAC)**, 곡당 **2~4분**, 전체 **20MB 이하** 권장
- **가사 있는 곡은 쓰지 않는다** (`instrumental: false`는 점검에서 차단)

## 2. 곡마다 확인할 것 (체크리스트)

- [ ] 라이선스 종류가 허용 목록인가: `CC0` / `PublicDomain` / `CC-BY` / `Purchased` / `Commissioned`
- [ ] **상업적 이용**(유료 앱·광고가 있는 앱 포함)이 허용되는가
- [ ] **게임(앱) 안 배경음악**으로 쓰는 것이 허용되는가 (영상 전용 라이선스가 아닌가)
- [ ] 금지 조건이 없는가: 비영리(NC), 변경 금지(ND), 동일조건 변경허락(SA), GPL 계열은 쓰지 않는다
- [ ] CC-BY면 **출처 표기 문구**를 그대로 복사해 `attributionText`에 넣었는가 (게임 설정 > 음악 저작권 표시에 나온다)
- [ ] **클래식**: 작곡은 퍼블릭 도메인이어도 **녹음(연주)의 라이선스**를 따로 확인하고 `recordingLicense`에 적었는가
- [ ] AI로 만든 곡이면: 도구 이름(`ai.generator`), 요금제(`ai.plan`), 상업적 이용을 허용하는 약관 증빙(`ai.commercialUseProof`)
- [ ] 증빙 파일을 `assets/audio/licenses/`에 저장했는가 (곡 페이지·라이선스 화면 캡처, 영수증, 계약서)
- [ ] 받은 날짜(`retrievedAt`, YYYY-MM-DD)와 출처 주소(`sourceUrl`)를 적었는가
- [ ] 파일을 `assets/audio/music/`에 넣고 `src/data/audio/music.json`의 임시 항목을 바꿨는가 (`status: 'final'`)
- [ ] `npm run lint:audio -- --release`가 통과하는가

## 3. 후보처 비교 (확인 필요 항목 많음)

| 후보처 | 라이선스 (요약) | 상업적 이용 | 게임 배경음악 | 출처 표기 | 맞는 장르 | 메모 |
|---|---|---|---|---|---|---|
| 퍼블릭 도메인 클래식 녹음 아카이브 (예: Musopen 등) | 곡마다 다름: 퍼블릭 도메인 / CC0 / CC-BY / **일부 NC·SA** | 곡마다 확인 필요 | 퍼블릭 도메인·CC0이면 가능 (확인 필요) | CC-BY면 필요 | 클래식 | 녹음 라이선스를 곡마다 꼭 확인 |
| 자유 이용 음원 사이트 (예: Pixabay Music) | 사이트 자체 콘텐츠 라이선스 | 허용으로 알려짐 (확인 필요) | 확인 필요 (음원만 따로 재배포 금지 조항 등) | 필요 없음으로 알려짐 (확인 필요) | 로파이·라운지·락 | 약관이 바뀐 적이 있어 받은 날 화면 캡처 필수 |
| 작곡가 개인 사이트 CC-BY 음원 (예: Kevin MacLeod / incompetech) | CC-BY 4.0 (또는 유료로 표기 면제 라이선스) | 허용 | 허용으로 알려짐 (확인 필요) | **필요** (정해진 문구) | 재즈·클래식풍·락 | 표기 문구를 그대로 복사 |
| 크리에이티브 커먼즈 아카이브 (예: Free Music Archive, ccMixter) | 곡마다 다름 (**NC가 많음**) | 곡마다 | 곡마다 | 대부분 필요 | 전 장르 | NC·SA 곡이 섞여 있어 걸러야 함 |
| 구독형 음원 서비스 (예: Epidemic Sound, Artlist) | 구독 라이선스 | 요금제에 따라 | **게임·앱 사용은 별도 조건 가능성 (확인 필요)** | 보통 필요 없음 | 전 장르 | 구독 해지 후 사용 범위 확인 필요 |
| 영상 크리에이터용 무료 음원 (예: 유튜브 오디오 보관함, Uppbeat) | 영상 플랫폼용 | 확인 필요 | **앱·게임 사용 불가일 가능성 높음 (확인 필요)** | 곡마다 | 전 장르 | 영상 전용이면 쓰지 않는다 |
| 음원 개별 구매 (스톡 음원 마켓) | Purchased (표준/확장 라이선스) | 허용 | 라이선스 등급에 따라 (게임은 확장 라이선스 필요할 수 있음, 확인 필요) | 보통 불필요 | 전 장르 | 영수증·라이선스 PDF 보관 |
| 작곡 의뢰 | Commissioned (계약) | 계약에 따라 | 계약에 명시 | 계약에 따라 | 전 장르 | 상업적 이용·게임 포함·기간 제한 없음을 계약서에 |

## 4. 지금 상태

- `npm run audio:placeholder`로 장르당 2곡의 **1초 무음 임시 파일**을 만들어 두었다 (재생 흐름 시험용, `status: 'placeholder'`).
- 평소 `npm run lint:audio`는 경고만, **`--release`는 임시 곡 때문에 실패하는 것이 정상**이다.
