# 단계 B 후보 목록 — 2000년대 (2000~2009)

> 승인 전 후보다. 본문(종목·뉴스) 작성은 승인 뒤에 시작한다.
> 실존 기업·인물명은 쓰지 않는다. 근거 문장에 나오는 기관·지수 이름은 이 문서(검토용)에만 쓰고, 게임 데이터에는 넣지 않는다.
> 확신도: **높음** = 널리 알려진 사실, 날짜·수치까지 확인 가능 / **중간** = 흐름은 맞지만 세부 수치·시점은 팩트체크 필요.
