# 그림 사양서 (그림 작가·AI 이미지 도구 전달용)

> 지금 화면의 그림은 모두 **임시 그림**(색 블록 + 영어 이름)이다. 아래 표의 **파일명 그대로** 진짜 그림을 만들어 `assets/` 아래 같은 경로에 덮어쓰면 화면에 바로 반영된다. 코드를 고칠 필요는 없다.
> 그림 목록의 원본 데이터: `src/ui/artManifest.json` (에셋 키 → 파일, 크기, 프레임 수). 임시 그림 다시 만들기: `npm run art:placeholder` (이미 있는 파일은 건드리지 않음, `-- --force`면 전부 새로).

---

## 1. 기준 해상도와 배율

| 항목 | 값 |
|---|---|
| 기준 해상도 | **180 × 320** 픽셀 (세로 화면) |
| 화면 배율 | **정수 배율만** 쓴다: `배율 = 내림(min(화면 너비 ÷ 180, 화면 높이 ÷ 320))`, 최소 1 |
| 360 × 640 기기 | 2배 → 360 × 640 (꽉 참) |
| 390 × 844 기기 | 2배 → 360 × 640 + 좌우 15px, 위아래 여분 → 배경 그림의 위아래 여백과 가장자리 색으로 채움 |
| 확대 방식 | `image-rendering: pixelated` (뭉개지지 않게 픽셀 그대로 키움) |

- **배경 그림은 180 × 400**으로 그린다. 가운데 **180 × 320**이 기본으로 보이는 영역이고, 위아래 40픽셀씩은 키가 큰 기기에서만 보이는 여백(잘려도 되는 곳)이다.
- 배경의 맨 왼쪽·오른쪽 열의 색이 화면 좌우 빈칸 색으로 이어진다. 가장자리는 단색에 가깝게 그려 둔다.

## 2. UI 안전 영역 (그림에 중요한 것을 두지 않는 곳)

기준 해상도(180 × 320) 기준. 화면에서는 배율만큼 커진다 (2배면 ×2).

| 영역 | 크기 | 무엇이 덮나 |
|---|---|---|
| 위쪽 | 위에서 **20픽셀** | 왼쪽 `NEWS!`, 가운데 설정 버튼, 오른쪽 보유 코인·x2 |
| 아래쪽 | 아래에서 **32픽셀** | 하단 탭 바 (탭 4개) |
| 기기 노치·홈 바 | 기기마다 다름 | 화면이 자동으로 더 비켜 준다 (`safe-area-inset`) |

임시 배경 그림에는 이 경계에 밝은 가로줄이 그려져 있다 (위 40+20 = 60, 아래 400−40−32 = 328 지점).

## 3. 팔레트 가이드 (어둡고 차분한 저채도)

- 전체 밝기는 낮게(배경 명도 15~30%), 채도는 낮게(20~35%). 형광·원색은 쓰지 않는다.
- 강조색은 몇 개만: **주황 코인** `#d9822b`, 즐겨찾기 별 `#d6b04a`, NEWS 배지 `#a8423a`, 하트 `#b5525a`.
- 시대별 분위기
  | 시대 | 거실·작업실 톤 | 주식창 색 세트(`htsSkin`) |
  |---|---|---|
  | 2000년대 | 따뜻한 갈색·나무 (`#3b3430` 근처) | 클래식 회색 (입체 테두리) |
  | 2010년대 | 회색·흰 벽, 평평한 가구 (`#33363a` 근처) | 평면 회색 |
  | 2020년대 | 어두운 회색, 간접 조명 (`#2a2d31` 근처) | 어두운 회색 |
- 주식창 색은 `src/data/eraTheme.json`의 `htsSkin.colors`가 CSS 변수로 들어간다 (그림 아님).
- **상승·하락 색(빨강/파랑/초록)은 그림에 쓰지 않는다.** 설정에 따라 바뀌는 글자 색이다.
- 비트코인의 ₿ 기호나 로고를 코인 그림에 쓰지 않는다. 실제 회사 로고·상표도 쓰지 않는다.

- `afterimage_sway`(잔상처럼 좌우)는 화면이 `idle0`을 좌우로 움직이며 반투명 복사본을 남겨서 만든다 (그림 추가 없음)

## 5. 파일명 규칙

- 영어 소문자, 숫자, 밑줄(`_`)만. 띄어쓰기·한글 금지.
- `종류_이름[_시대].png` (예: `living_2000s.png`, `dog_senior.png`)
- 폴더: 배경 `art/bg/`, 움직이는 것 `art/sprites/`, 아이콘 `art/ui/`
- 새 그림을 **추가**할 때만 `src/ui/artManifest.json`에 한 줄 추가한다 (교체는 덮어쓰기만).
