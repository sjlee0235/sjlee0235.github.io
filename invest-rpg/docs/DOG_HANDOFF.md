# 강아지 새 디자인 (포동포동 시바, 옆모습 v3: 관절 연결형) 전달

## 파일
- `dog/{pup|adult|old}_{pose}.png` — 투명 PNG, **48×40**, 도트 1칸 = 1px (게임이 ×3). 27장
  - pose: `stand` 서기 · `sit` 앉기 · `lie` 눕기 · `walk0/walk1` 걷기 2프레임 · `happy0/happy1` 터치 1번(서서 웃고 꼬리 흔들기) · `belly0/belly1` 5번 연속 터치(배 보이기, 발·꼬리 움직임)
- `hearts/hearts_{0,1,2}.png` — 배 보이기 때 몸 위에 겹치는 하트 3프레임 (48×40, 강아지와 같은 기준점)
- `dog_poses_fluffy.jpg` — 전체 자세 확인 시트

## 기준
- 모든 자세 **몸·얼굴 모두 옆모습, 오른쪽을 봄**. 왼쪽으로 걸을 때는 좌우 뒤집기.
- 바닥에 닿는 줄 = 위에서 38번째 줄(행 37). 기존 스프라이트(42×40)의 바닥 논리 행은 29였으므로 기존 위치를 유지하려면 새 그림의 왼쪽 위를 `(ox − 3, oy − 8)`에 놓는다.
- 크기(서기 기준 실제 도트 크기): 아기 31×30px, 성견 38×35px, 노견 35×32px. 성견 > 노견 > 아기. (v3.2: 몸을 줄이고 머리 비율을 키워 더 귀엽게)
- 아기: 몸이 작고 머리·눈이 큼. 노견: 처진 눈썹, 하얀 털 섞인 입가, 몸이 낮음.
- 밤/낮 별도 그림 없음 (기존과 동일).

## v3 변경점 (v2 대비)
- 몸통·목·다리·꼬리를 하나의 실루엣(외곽선 1겹)으로 연결. 허벅지·어깨 안쪽 윤곽선, 가슴 털, 양말 무늬 추가.
- 몸통은 v2보다 슬림하되 배 라인이 움푹 패이지 않도록 가슴~엉덩이를 이어지는 포동한 곡선으로 (배 허리 잘록함 제거).
- 터치 웃음(happy0/1): 눈을 뜬 채(하이라이트 유지) + 눈썹 올림 + 입 벌린 웃음.
- 배 보이기(belly0/1): 머리를 상하 반전(턱이 위, 귀가 바닥), 네 발 위로, 꼬리 흔들림.
- 파일명·크기(48×40)·기준점은 v2와 동일하므로 그대로 교체 가능.
