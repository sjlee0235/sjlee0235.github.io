# 투자 RPG (가제)

모바일(iOS/Android)용 2D 픽셀 RPG풍 투자 시뮬레이션 게임.
감으로 투자하다 전 재산을 잃은 20대 후반 청년이 공부하고, 인형 눈 붙이기로 모은 1만 비트로 다시 시작하는 이야기.
교육용으로도 쓸 수 있도록 **연습 모드**와 **실전 모드**를 둔다.

**현재 단계: W1 — 게임 규칙 엔진** (화면·그림·저장·결제·실제 광고 연동 없음)

---

## 1. 실행 방법

### 준비 (처음 한 번)
1. [Node.js](https://nodejs.org) **22.18 이상** (LTS 버전)을 설치한다.
   - Node.js = 컴퓨터에서 자바스크립트/타입스크립트를 실행해 주는 프로그램
2. 터미널을 열고 이 폴더로 이동한 뒤 필요한 도구를 설치한다.
   ```bash
   cd invest-rpg
   npm install
   ```

### 자주 쓰는 명령

| 명령 | 하는 일 |
|---|---|
| `npm test` | 자동 테스트 전체 실행 (게임 규칙이 맞는지 검사) |
| `npm run demo` | 2000년대 한 시대를 실전 모드로 끝까지 돌려 보기 (시드 42) |
| `npm run demo -- practice` | 연습 모드로 데모 (뉴스마다 관련 테마·해설 출력) |
| `npm run demo -- real 7` | 실전 모드, 시드 7 (같은 시드 = 같은 결과) |
| `npm run typecheck` | 타입 검사 (+ 엔진이 화면 코드 없이 컴파일되는지 검사) |
| `npm run check` | 타입 검사 + 테스트 한 번에 |

### 화면(W2 이후)에서 엔진을 쓰는 법

```ts
// 홈 화면에서 고른 모드로 시작
const game = new Game({ eras: ALL_ERAS, seed: 12345, mode: 'practice' }); // 또는 'real'

// 화면 쪽 타이머가 5초마다 호출. 연습 모드 팝업 중이면 아무 일도 안 일어난다.
setInterval(() => {
  const r = game.advanceTick();
  if (r.advanced && r.news) showNews(r.news);                // 연습: 팝업(시간 정지) / 실전: 알림(시간 계속)
  if (r.advanced && r.settlement) showSettlement(r.settlement); // 시대 정산 화면
}, 5_000);

// 연습 모드 팝업
game.getNewsGuide(news);   // '관련 테마' 목록 + 호재/악재 + '해설 보기' 내용
game.confirmNews();        // '확인' → 10초(2틱) 뒤 반영

game.grantAdReward();      // 연습 모드: 광고 시청이 끝난 뒤 호출 → +3,000 비트
game.buy('2000s-defense', 3);
game.getStockList();       // 즐겨찾기 우선 정렬된 종목 목록
game.getPortfolio();       // 현금, 총 자산, 종목별 평균가·손익
game.getChart('2000s-defense'); // 최근 20분 가격
game.startNextEra();       // 정산 화면 이후 다음 시대로
```

## 3. 데이터 작성 방법

### 뉴스 한 개의 구조
```jsonc
{
  "id": "2000s-n19-oil-147",
  "title": { "ko": "...", "en": "..." },
  "body":  { "ko": "...", "en": "..." },
  "effects": [
    { "themeId": "refining", "impact": 7,  "link": "direct",   "explanation": { "ko": "왜 호재인지", "en": "..." } },
    { "themeId": "travel",   "impact": -3, "link": "indirect", "explanation": { "ko": "유가↑ → 항공권↑ → 여행↓", "en": "..." } },
    { "themeId": "market",   "impact": -1, "link": "direct",   "explanation": { "ko": "시장 전체", "en": "..." } }
  ],
  "source": { "event": "참고한 실제 사건", "date": "2008-07-11", "impactRationale": "근거", "needsVerification": true }
}
```
- `link`: `direct`(1차, 기사만 읽어도 알 수 있음) / `indirect`(2차, 한 번 더 생각해야 함)
- `themeId: "market"`: **시장 전체**에 영향. 각 테마 영향과 **합산**된다 (예: 시장 -3 + 투자은행 -10 → -13 → -10으로 잘림)
- `explanation`: 연습 모드 '해설 보기'에 그대로 나온다
- `source.fictional: true`: 실제로는 일어나지 않은 가상의 결과

### 낌새 → 결과 스토리라인
```jsonc
{
  "id": "2000s-story-nk-nuclear",
  "signals":  [ /* 낌새 뉴스 1개 이상, 영향도 ±4 이하 */ ],
  "branches": [
    { "tone": "negative", "news": { /* 실제 결과 */ } },
    { "tone": "positive", "weight": 1, "news": { /* 다른 결과 (fictional) */ } }
  ]
}
```

### 검사 (`npm test` 시 자동)
- 테마 20개 (긍정 7 / 부정 7 / 중립 6), 테마당 종목 1개, 테마 id로 `market` 사용 금지
- 영향도는 -10~10 정수, `link`와 한·영 해설 필수
- 낌새 뉴스 영향도 ±4 이하, 결과 뉴스는 낌새보다 커야 함, 결과 갈래 2개 이상
- 한국어·영어 텍스트, 실존 기업명 금지어 (해설 포함)
- **뉴스 공급량**: 시대 하나에 뉴스 자리가 최대 40개 생길 수 있다. 단독 뉴스 1개 = 1자리, 스토리라인 = (낌새 수 + 1)자리.
  모드별로 이보다 적으면 경고를 띄운다. 연습 모드는 1차 영향이 있는 뉴스만 센다.

## 4. 확정된 규칙 (요약)

| 항목 | 값 |
|---|---|
| 1틱 | 게임 시간 **5초** (모든 시간은 config.ts에 초 단위로 적혀 있어 틱 길이를 바꿔도 자동 환산) |
| 시대 길이 | 2시간 = 1,440틱, 시대 3개: 2000s → 2010s → 2020s |
| 평소 틱 변동 | -3.0% ~ +3.0%, 소수점 1자리 |
| 1분 누적 한도 | 변동률 합 ±3% (1분 = 12틱) |
| 뉴스 시점 | 불규칙. 첫 뉴스 1~3분, 이후 **3~6분** 간격 무작위 (시대당 약 20~40개) |
| 뉴스 영향 | 영향도(-10~+10) × 3%, **10초 뒤** 한 번에 반영 |
| 낌새 → 결과 | 첫 낌새 뉴스 후 **15분 안** 무작위 시점에 결과 뉴스 (긍정/부정 무작위) |
| 뉴스 후 관성 | 반영 후 **20초(4틱)** 동안 틱마다 유지 60% / 반대 20% / 정지 20% |
| 연습 모드 | 뉴스 팝업 시 시간 정지, 관련 테마·해설, **1차 영향만** 반영, '확인' 후 10초 뒤 반영, 광고 보상 +3,000 비트 |
| 실전 모드 | 뉴스가 떠도 시간 계속, 뉴스가 뜬 뒤 10초 뒤 반영, 1·2차 영향 모두 반영, 광고 보상 없음 |
| 가격 | 시대 시작 1,000 비트, 정수, 최소 1 |
| 시작 자금 | 10,000 비트, 시대 종료 시 전량 청산 후 이월 |
| 차트 | 최근 20분 (240개) |

## 5. 가정한 규칙 (기획에서 정하지 않아 임의로 정한 것 — 바꾸고 싶으면 알려주세요)

### 뉴스 일정
1. **첫 뉴스는 시대 시작 후 1~3분** 사이에 뜬다. 시작하자마자 뜨지 않아서 시장을 둘러볼 시간이 있다.
2. 마지막 뉴스는 반영(10초)과 관성(20초)이 시대 안에서 끝나는 시점까지만 뜬다.
   시대 끝 무렵에 다음 간격이 들어갈 자리가 없으면 마지막 몇 분은 뉴스 없이 끝난다 (최대 6분).
3. 일정은 시대 시작 때 시드로 한꺼번에 정한다. 단독 뉴스와 스토리라인을 섞어서 무작위 순서로 배치하고, 같은 뉴스는 다시 나오지 않는다.
4. **스토리라인 배치**: 낌새가 나오면 첫 낌새로부터 15분 안에 있는 빈 뉴스 자리 중 하나를 골라 결과 뉴스를 넣는다.
   낌새가 2개면 두 번째 낌새는 첫 낌새 다음 빈자리에 들어간다. 15분 안에 자리가 부족하면(시대 끝 무렵) 그 스토리라인은 이번 시대에서 건너뛴다.
5. 결과 갈래는 `weight`(기본 1:1) 비율로 무작위로 정한다.
6. 뉴스 공급이 자리보다 적으면 뒤쪽 자리에는 뉴스가 뜨지 않는다.
7. 시대 안에서 뉴스 순서는 **실제 연대순이 아니다**.

### 연습 / 실전 모드
8. 연습 모드에서는 뉴스의 **1차(direct) 영향만** 주가에 반영하고, 해설도 1차 영향만 보여준다. 1차 영향이 하나도 없는 뉴스(2차 해석 전용)는 연습 모드에 나오지 않는다.
   (다른 방법: 연습 모드 전용 뉴스를 따로 쓰기 — 원하면 바꿀 수 있음)
9. 연습 모드 팝업이 떠 있는 동안에는 매매할 수 없다. '확인'을 누른 뒤 10초 안에 매매할 수 있다.
10. 실전 모드에서는 뉴스가 뜬 직후부터 매매할 수 있다.
11. 광고 보상은 연습 모드에서만, 시대 중 언제든(정산 화면 포함) 받을 수 있다. 횟수 제한은 기본 없음 (config `adRewardMaxPerEra`로 설정 가능).
12. 정산 수익률은 광고 보상을 빼고 계산한다: **수익률 = (종료 자산 - 시작 자산 - 광고 보상) ÷ (시작 자산 + 광고 보상)**.

### 주가
13. **1분 윈도우는 고정 구간**이다 (1~12틱, 13~24틱, …). 그래서 경계에서는 연속 2틱 합이 최대 ±6%가 될 수 있다.
14. 누적 한도는 변동률의 **단순 합**이다 (복리 아님).
15. 랜덤 변동은 -3.0~+3.0%에서 균등하게 뽑은 뒤 남은 한도 안으로 자른다(clamp).
16. 뉴스를 받은 종목은 그 틱에 정확히 "영향도 × 3%"만 적용된다. 그다음 틱부터 그 종목만의 새 1분 윈도우가 시작된다.
17. **관성 크기**: '유지'·'반대'일 때 크기는 0.1~3.0%에서 무작위다. 관성 틱도 1분 한도 안에 들어가야 한다.
    그래서 한도를 다 쓰면 '유지'가 뽑혀도 0%가 될 수 있다.
18. 관성 방향은 그 종목에 실제로 반영된 변동(시장+테마 합산)의 부호를 따른다.
19. 시장 영향과 테마 영향이 합쳐져 0이 되면 그 종목은 영향 없음으로 보고 평소처럼 움직인다.
20. 한 뉴스 안에 같은 테마가 두 번 나오면 합산 후 ±10으로 자른다.
21. 가격 = 반올림(이전 가격 × (1 + 변동률)), 0.5 올림, 최소 1.
22. 시드: 시대 id별로 주가용 난수를 따로 만들고, 뉴스용 난수는 시대 id와 모드별로 따로 만든다. 그래서 같은 시드라도 연습과 실전의 뉴스 순서는 다르다.

### 계좌·목록 (W1과 같음)
23. 평균 매수가는 이동평균, 수수료는 매입원가에 포함(기본 0), 구입 순서 = 처음 산 순서.
24. 매수 시 즐겨찾기 그룹 맨 위에 자동 추가, 시대가 바뀌면 즐겨찾기 초기화.
25. 목록 색상은 시대 시작가 대비 등락 기준.

## 6. 검토가 필요한 점

- **밸런스 (가장 중요)**: 뉴스 영향이 정해져 있어서 "뉴스를 보고 바로 호재 종목을 사는" 단순 전략이 너무 강하다.
  100개 시드 시뮬레이션 기준 시대당 수익률 중앙값은 **연습 +796%, 실전 +1,457%**다. 관성까지 더해져 W1 때(+447%)보다 커졌다.
  해결 방법 후보: (a) 실제 반영량에 무작위 폭 추가 (b) 일부 뉴스는 이미 가격에 반영됐거나 반대로 움직임 (c) 실전 모드에서 10초 지연 없애기
- **5초 틱과 1분 한도**: 1분 = 12틱인데 틱당 ±3%, 1분 합 ±3%라서 한도에 자주 걸린다.
  평소 틱의 **15%가 0.0%**(가격 정지)로 나온다. 틱당 최대를 ±1.5%로 줄이면 8.5%로 낮아진다 (config `tickMaxRate: 15`).
- **역사와 다른 결과**: 스토리라인의 다른 갈래는 실제 역사와 다르다 (예: 이라크가 무기사찰을 수용해 전쟁 회피).
  교육용으로는 헷갈릴 수 있어서, 화면에 "가상 시나리오" 표시를 하거나 연습 모드에서는 실제 결과만 나오게 하는 방안을 검토할 필요가 있다.
- **뉴스 분량**: 시대당 최대 40자리를 채우려면 시대마다 단독 뉴스와 스토리라인을 합쳐 40자리 이상 필요하다. 2000년대는 실전 40 / 연습 34자리다.
  3개 시대 × 40개 이상 × 한·영 × 해설은 작성량과 사실 확인 부담이 크다.
- **광고 보상 무제한**: 연습 모드라도 무제한이면 돈 관리 학습 효과가 약해진다. 시대당 횟수 제한(예: 3회)을 추천한다.
- 2000년대 테마 분류 중 **건설(부정)**, **금(중립)** 재검토 필요. 온라인게임·한류·휴대폰 테마는 뉴스가 1~2개로 적다.
